# 初代商品页骨架（对照红色妮可）

页面顺序（方便以后商品页直接截图）：

封面 → 困境钩子 → 数字四行（N 大类／N 词／N 出处／N 延展）→ 三大类／章节页 → 词条页 → 路径与「你的词典」→ 延展资源 → 更新日志 → 购前须知

## 对照表

| 她的 | 她怎么做 | 我们的 | 改什么 |
|---|---|---|---|
| 标题 | 万物隐喻·开启艺术创作的159种方式 | 名字·把 N 种感觉做成作品 | 数字换成词数 |
| 困境钩子 | 找不到切入点？思维受限？…… | 撞款？有感觉做不出？参考只会刷 Pinterest？…… | 全换成圈子的话 |
| 资质 | 2 年、150＋教学、皇艺 | N 个词、N 条出处、N 种媒介、每条带链接 | 用可核验代替背书 |
| 章节 | 19 章学院议题 | 美学范畴章＋圈子词 | 章名换成圈子词 |
| 条目 | 物性／隐喻／材料／建议／参考 | 核心／元素／手法／出处／分媒介／反例／相邻词 | 加三个字段 |
| 方法论 | （详情未全见） | 感觉→元素→手法→出处→媒介，加「你的词典」模板 | 只要一条路径 |
| 延展资源 | 网站、书单、片单，福利赠送 | 出处站点＋片单书单，同样写福利赠送 | 照抄结构 |
| 适用人群 | 作品集学生／艺术家／策展／老师 | 美工／写手／coser／剪刀手／画手 | 全换 |
| 购前须知 | 电子文档、飞书发送、不退换 | 照抄 | 无 |

## 产品内模板页

「你的词典」：一页空表，字段跟配方／词条页一样，让买家自己填。飞书空表零成本，把「建立你的词典」那句形而上的话落地。

空词条七字段：核心、元素、手法、出处、分媒介、反例、相邻词。
