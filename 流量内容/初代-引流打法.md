# 初代引流打法（红色妮可拆解 → 我们）

来源：Claude 对红色妮可／「妮可的时时刻刻」的拆解。

## 她的四个动作

1. **双账号分工**
   - 老账号「妮可的时时刻刻」：流量端。单条笔记＝知识库里的一条（物件作为概念），视频。
   - 新账号「红色妮可」：成交端。「为什么」长文讲过程痛点；简介写官方店铺，老号导流过来。
2. **内容＝产品的一条**：看完就知道买了能拿到什么，又拿不走整本。标题语法固定：「物件作为概念」。
3. **「为什么」做引流，物件做产品**：过程钥匙做内容，不做产品交付。
4. **定位宽，标签窄**：文案说「所有创作者」，标签打 #作品集 #艺术考研 #艺术生（有 deadline、有预算）。链接放在作者自己的评论里。

## 照到我们身上

| 层 | 做法 |
|---|---|
| 流量端 | 单条笔记＝一个情境的一组手法。清单形＋名字，例：「吵架｜4 个大师手法」。语法可定成「情境｜手法作为什么」。 |
| 成交端 | 「为什么」文章，写作痛点版（为什么你写的吵架像小学生吵架、为什么重逢像相亲……）。 |
| 上级流量池 | 「电影感」「镜头语言」「氛围感」等：引流笔记打的池子，不是买家；买家在下一层。 |
| 标签 | 每条打三类之一：#同人 或 #网文 或 #短剧剧本，再加 #写作／#创作；身体类加 #vlog #cos。不打 #艺考 #作品集 #考研。 |
| 信任 | 不承诺录取／过稿／签约；每条带原始出处（契诃夫、是枝裕和自己就是资质）。 |
| 人群 | 内容按情境生产，标签按人群轮换，任何一群不超过三分之一。 |

## 验证上级流量池的词（当时给的）

「电影感」「镜头语言」「短片」——切最多收藏，看收藏比点赞高不高，评论区有没有「想拍出这种感觉但不知道怎么拍」。
