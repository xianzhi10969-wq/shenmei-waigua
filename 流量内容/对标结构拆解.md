## 二、各簇怎么翻页

### A. 一天一风格百科壳

**代表：**  
`2023-02-13-设计师奈奈酱-每天认识一种艺术风格梦核.md`、  
`2023-02-20-设计师奈奈酱-每天认识一种艺术风格Gurokawa.md`、  
`2026-09-02-设计师奈奈酱-每天认识一种艺术风格CandyGore.md`

**封面：** 竖屏视频第一帧当信息流。梦核那条是暗红噪点室内 + 一行定义字幕；Gurokawa 是人像特写直接开讲；Candy Gore 则先出黑底标题卡「带你每天认识一种艺术风格」+ 白框风格名，再进插画。系列感不靠副标题堆卖点，而靠固定句式「每天认识一种艺术风格—××」把风格名钉死。封面无价格、无 CTA。

**内页机制（以梦核／Candy Gore 的抽帧为准）：**  
整条是「字幕拼成一句定义」+「画面换风格例图」。图与图之间不是「问题→答案→练习」的教学楼梯，而是把一条百科定义拆成时间轴上的碎句：先声明它是什么美学，再补材质／情绪／场景词，最后落到「奇怪、不安」一类收束感。Candy Gore 更明显——图 03 说矛盾，图 04–05 用甜与血腥对照，图 08–11 把机制说成「甜味负责靠近／怪异负责记住」，末帧把选择题抛给观众（可爱还是不舒服）。没有单独的产品页、没有价格数字。

**正文与字卡：** 信息几乎全在视频字幕里；笔记正文通常是短 caption + 话题标签，不承担逐页讲解。

**与审美外挂：** 亲缘在「一条笔记 = 一个风格词条」的百科密度；初代梦核草稿也走「一个感觉名 + 历史出处」这条线，但是静态图文而不是口播混剪。

### B. 手法清单壳（写作）

**代表：**  
未几：`2026-03-19-…歧疑.md`、`2026-04-27-…倒喻.md`、`2026-06-25-…牵丝.md`  
九公子：`2026-01-19-…冷笔触.md`、`2026-01-27-…咬尾句.md`、`2026-04-04-…否定叙事.md`

**封面：** 几乎同一套字卡——深灰或浅灰底、左上引号「66」、中间两行「一个很绝的写作手法：××」、左下「右划查看全文」+ 右下箭头。系列钉法极硬：标题语法固定，只换手法名。九公子「否定叙事」有时会把一句金句（「你要写爱，就不能只写爱」）放在信息流第一张，系列壳推到图 02，等于先用断言钩住再亮系列名。

**内页机制（以歧疑 9 页为例，同壳可对读倒喻／牵丝）：**

| 页 | 结构角色 |
|---|---|
| P1 | 系列封面：手法名 + 右划提示 |
| P2 | 痛点钩子：用两句「普通人会怎么写」的俗句对照，引出今天的手法名，再给一句粗定义 |
| P3 | 定义展开 + 经典例句（张爱玲等），黄字标出关键半句 |
| P4 | 第二例句 + 与相近手法的辨析（歧疑 vs 逆挽） |
| P5 | 「为什么有力量」：讲读者预期／心理落差，然后预告「三个实用技巧」 |
| P6–P7 | 技巧 1–3：每条是「设疑半句 + 反转底牌」的成对例句 |
| P8 | 练笔指令：截断一句再补反转；再给两对开头／结尾示范 |
| P9 | 收束金句 + 自我介绍 + 评论区互动（请读者写一句） |

九公子咬尾句／冷笔触页数略短（约 6–7），但仍是同一楼梯：**钩子例句 → 定义 → 典型句式分类 → 为什么击中人 → 核心技巧 → 小练习对照（普通写法 vs 手法写法）→ 总结金句**。否定叙事多一页「负空间」理论，练习页留空让读者填，但空的是开放练习位，不是商品 CTA。

**价格／销量：** 壳内无价格。成交若存在，在账号别的笔记或店铺，不在这套手法卡里。

**与审美外挂：** 亲缘极近——「情境／手法名」单条知识密度、系列标题钉法、字卡承担全部教学。初代打法里写的「单条笔记＝一个情境的一组手法」就是在描述这层结构，只是初代草稿还没做成这套灰底字卡。

### C. 关键词／风格合集壳

**代表：**  
涌动鲤教程对页：`2025-07-04-涌动鲤-如何快速找到风格灵感教程.md`  
涌动鲤目录合集：`2025-07-14-涌动鲤-30个关键词快速找到风格灵感.md`、`2025-08-09-涌动鲤-小众梦核美学合集.md`  
熊脑丝儿：`2025-08-05-…色彩法.md`、`2025-08-26-…甜到吓人的风格.md`、`2026-01-07-…偷感很重的视觉风格.md`  
大斌搜索词：`2025-07-26-大斌设计课堂-超全搜索词找到风格灵感图.md`  
雾气花洒关键词：`2026-05-22-雾气花洒-Pinterest不会主动告诉你的关键词.md`

**封面：** 两类。一类是白底大字／拼贴（涌动鲤「30种设计风格」手绘圈 + 散点参考图；「20种核美学」散点拼贴）。一类是方格纸／点阵标题卡（熊脑丝儿），信息流 og 封面却常常用内页某一号风格卡（例如偷感系列用「06 针孔摄影美学」当封面），标题卡反而是轮播里的字卡。雾气花洒是人像指向屏幕 + 打字机纸列出四个英文词。封面普遍无价格。

**内页机制：**

1. **涌动鲤教程对页（约 16 页）**  
   偶数页：Pinterest 搜索网格截图，下半白底居中「英文名 / 中文译名 / 大号序号」。  
   奇数页：说明卡——黄条情绪标签、特征、适用场景。  
   整条是「搜得到的证据页」和「读得懂的释义页」交替，不是一页讲完再翻下一风格。

2. **涌动鲤 30 词合集（约 8 页）**  
   P1 封面目录感；P2–P7 按 `#01-05`…`#26-30` 五图横排 + 分类小标题（自然与抽象／潮流亚文化／…）；P8 两列总目录收束。每一页是「一批词的货架」，几乎不做长定义。

3. **熊脑丝儿单风格卡（偷感系列约 7 页）**  
   P1 标题卡；P2–P7 每页同一壳：上半该英文关键词的 Pinterest 瀑布流，下半左图右「大号编号 + 色底中文名 + 短释义 + 适用」。系列靠编号连续推进，像词典词条墙。色彩法那条会先插一张「色系总表」当方法页，再进入词条卡。

4. **大斌搜索词（约 19 页）**  
   黑底统一壳：风格中文名、特点一两句、一行「搜索词：…」，旁边常配参考缩略。比涌动鲤更「词条列表」，少对页释义。

5. **雾气花洒关键词视频**  
   录屏搜词：底部气泡打出正在搜的英文，片尾切白底样图 + 粉字词名。结构是「演示检索」而不是「印刷词典」。

**与审美外挂：** 亲缘在「可检索的风格名／关键词」；审美外挂若做成词条库，这簇是流量侧「外挂大脑」的壳，但交付深度通常浅于红色妮可的物件系统。

**封面：** 视频第 0 帧常兼封面：作者出镜 + 手写大字（Creativity／Website），或撕纸洞露脸（喜谱来风格篇）。留白的贝果用一张设计海报当冷开场，几秒后才切白底录屏口播。

**内页机制（留白的贝果，约 10 抽帧）：**

| 页／帧 | 结构角色 |
|---|---|
| 01 | 海报冷开场，无口播字幕 |
| 02 | 三张「类似图」横排，字幕说已经快速找到一堆类似 |
| 03–04 | 提出「若要围绕它做调研」+ 点出颗粒感／氛围感等模糊词 |
| 05 | 痛点清单页：识别不准、风格不统一、不属于一套语言 |
| 06 | 亮出完整 Prompt 卡片（工具本体） |
| 07–09 | 聊天界面：贴图 → 模型吐出分层关键词 → 选中某一词 |
| 10 | 搜索结果页验证「复制关键词去搜」；字幕收束「快去试」 |

雾气花洒「小众灵感库」是：出镜承诺 → 网站网格 → 以已存海报为例 → 图层拆解 → 同款花体字 → 二创对照 → 「直接上手拆解」。失效扫描那条则是：位图工具参数页 → 找参考 → 把规则收成 AI skill 文档 → 上传照片生成。喜谱来风格篇用编号大色块 1／2／3 切段（审美管理 → 灵感库 → 删除不喜欢的元素），中间插入硬件产品特写，结构和纯教学略有混杂。

**价格：** 演示壳本身通常不标价；喜谱来中间会出现具体硬件，那是软植入，不是店铺价签页。

**与审美外挂：** 亲缘在「把找风格的动作工具化」；审美外挂若强调检索，这是动作层，不是词条内容层。

### F. 物件／案例拆解 → 产品演示壳（红色妮可）

**代表：**  
流量偏理念／产品：`2025-10-31-红色妮可-你99%的痛苦都来自选题模糊和逻辑混乱.md`、`2026-03-07-…用具体表达抽象.md`、`2026-03-13-…艺术隐喻库.md`

**封面两种极端：**  
痛点帖是乳白底纯字大海报（红毛笔标题 + 底部规格「19×159×1000」）；案例帖封面可以**零文字**——满版手套俯拍，或欧根纱作品拼图，标题全靠信息流标题栏承担。

**内页机制（手套篇 11 页，最能看清「案例段 + 产品段」接缝）：**

| 页 | 结构角色 |
|---|---|
| P1–P4 | 纯作品图，对应正文里的四种方法（重复／拉长／换皮肤／代替身体），图上无字 |
| P5 | 突然切多设备产品实拍，叠四条规格卖点 |
| P6 | 飞书词条检索演示（输入主题关键词跳转物件） |
| P7 | 19 章节目录总览 |
| P8 | 艺术家案例一键跳转 |
| P9 | 目录定位 + 案例预览 |
| P10 | 多端打开飞书延展库 |
| P11 | 限时赠送审美资料库 |

「用具体表达抽象」「隐喻库」「99%痛苦」几条则几乎**没有案例摄影段**，从封面理念句直接进入产品 UI 轮播：规格页 → 衣架词条完整界面 → 目录／搜索「记忆」→ 案例跳转 → 附赠资料库。规格数字（19／159／1000）在封面或第二页反复出现，承担「商品是什么」的说明，价格数字往往不写进图，而靠店铺或评论承接。

欧根纱篇：P1–P4 作品照相册；P5 起切到「材料篇」产品规格（175 材料等）；其后是材料词条六维导航、相关术语、章节列表、赠品页——同一接缝，只是产品从「物件隐喻」换成「材料篇」。

**与审美外挂：** 这是产品本体最亲的一簇：单条公开内容像词条试用，后半页变成货架说明书。初代引流打法正是从这里拆出「内容＝产品的一条」「为什么做引流」。

| P4 | 真实店铺页：两件商品、到手价、已售 |

| P7 | 「普通人能借什么」四步缩小场景 + 免责声明 |

9.9 元篇拉到 8 页，多拆「代表笔记怎么获客」「为什么这个价能卖」「内容→主页→商品路径」，末页给 AI 找题提示——仍是观察者口吻，不是自己的课程大纲。4.99 元篇更短：证据 → 评论里的具体问题 → 从自用麻烦做成工具的四步。

**与审美外挂：** 不提供内容壳，提供「低粉＋具体交付＋价格锚」的成交观察；158 那条拆的正是红色妮可商品。

## 三、封面／标题／正文分工（跨簇）

1. **系列钉法最硬的是手法壳与一天一风格壳**：标题只换关键词，封面版式几乎不动，收藏和追更靠「下一枚词条」。  
2. **合集壳用数量词钉系列**（30 种、20 种、16 构图、第一期／第二期色系），封面是目录海报，内页是货架。  
3. **成交壳反着来**：封面先甩价格与已售，内页再证明链路；教学壳则把价格藏到店或末页。  
4. **字卡与摄影的分工**：手法／银莎／Finn／饽饽君——字卡即内容；奈奈酱／琪仔——画面气氛 + 字幕定义；红色妮可案例帖——前半纯图后半纯 UI；电子艺术库——几乎只有样张。  
5. **视频帖的「页」**是时间轴抽帧，结构角色仍可按钩子／定义／对照／演示／收束来读，只是切换更快。
