`assets/` 包含吊灯、十张裁片、十张完整来源图（九张案例图＋《秋千》）和五份字体；`content.json` / `cases.json` 保存真实展示数据与对应关系；`licenses/` 为字体许可；`checks/scroll.py` / `previews/scroll-checks.json` 为本轮交互核验；`audit/` 为原Figma结构与受保护素材记录。`MANIFEST.json` 列出文件大小与SHA-256，供完整性核对。
