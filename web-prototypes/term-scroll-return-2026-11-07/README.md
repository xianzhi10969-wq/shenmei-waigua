# Coquette｜可向上返回吊灯的滚动修正版

2026-11-07，针对用户“从风格图谱无法往上翻”的修复。独立目录，原8788版本保留。

## 本轮行为

原实现把吊灯和图谱绝对定位叠放，只允许图谱内部滚动，所以开场不属于上方可达内容。本版统一为原生滚动容器；吊灯、纸白转场和图谱的可见度随滚动位置双向变化。开场等待下滑，不会载入后自动消失。向上可从案例经过图谱返回吊灯；鼠标滚轮、触屏、键盘均沿同一滚动路径。

图谱标题先出现，然后01–10图与编号同现。离屏下一图继续等待滚动；回看开场会暂停显现，重新下滑则从已有进度继续。快速跳过图谱进入正文时显示全部内容，避免空白正文。减少动态效果偏好下使用即时切换。底部“回到开场”用于回到顶部并重置显现；进度滑杆仅供审阅。

## 查看

在此目录运行 `python3 -m http.server 8789 --bind 127.0.0.1`，打开 http://127.0.0.1:8789/ 。`?cases=1`可直达案例，但仍可向上回到吊灯。

checks/scroll.py 与 previews/scroll-checks.json 记录本次390/1440滚轮、键盘、手机触屏仿真、减少动态效果、图谱顺序、案例跳转与返回的验证。双端实图已查看，PNG仅本地。既有图片、字体、拼贴几何与3案例正文不改；没有新的Figma/飞书写入或生产部署。此为独立Coquette原型修复，视觉待用户审。
