# 「审美外挂」网站分镜稿 V2（游乐园版）

> 本文档面向未参与前期讨论的协作者（人或 AI）。读完这份文档应当能独立开始设计与开发，不需要补充背景。

---

## 0. 产品背景

**是什么**

一个付费网站（198 元，付费后获得访问链接，站内无付费墙）。它不教创作，它帮人认识自己的审美。

**用户的真实状态**

用户只会说一句模糊的「我想提高审美」。他有两个痛点：

1. 他形容不出自己的感觉，需要有人当他的嘴替。
2. 审美名词（侘寂、巴洛克、暗黑学院）听起来高大上，但他感觉这些词跟自己没关系。

**产品的解法**

**「感觉」是人和美学风格之间的桥。**

感觉有两侧，都是感觉，只是人称不同：

- 用户侧写成**第一人称句**：「我不想被看穿」
- 风格侧写成**描述**：暗、克制的悲伤

两边一匹配，桥就通了。暗黑美学吸引的就是不想被看穿的人。

**关键设计约束**

用户侧必须是他会脱口而出的话，不能是形容词。

旧版网站做过 40 个「感觉入口」（暗、神秘、温柔），失败原因是这些是描述词，要求用户先具备描述自己的能力，而他恰恰没有。

第一人称句不要求他形容任何东西，只要求他认出「这是我」。

**第三个必需项：可玩性。**

没有可玩性，这个网站就是谷歌艺术。让人愿意待在里面、读得开心，这也是交付的一部分。

## 1. 为什么是游乐园

上一版网站的世界观是教堂（花窗、祭司、星星、吊灯），已废弃。

废弃原因：延展性太差。做新功能时，除了教堂花窗想不出别的装饰语言，功能和世界观不在同一个体系里。

游乐园的好处是**它自带层级，而且和内容层级一一对应**：

| 内容层        | 乐园层        |
| ---------- | ---------- |
| 全站         | 乐园         |
| 24 个一级专题   | 主题园区（入口牌楼） |
| 101+ 个风格词条 | 园区里的一个设施   |
| 词条详情页      | **坐上这个设施** |
| 用户的感觉      | 一条园区小火车线路  |

**最重要的一条比喻：**

一个风格就是一个设施，读一个词条就是坐上它。所有视觉设计都应服从这条，不要把设施当装饰物乱摆。

## 2. 全站视觉与交互规则

### 2.1 画风：像素风

选像素风的原因不是风格偏好，是**一致性可以靠机械规则保证，不依赖审美手感**。

下面这张规格表是硬性的，每次向 AI 生成图片时都应完整附上：

（这个是Claude写的，全站统一32色这个事情我不确定啊！参数也是他写的。除了“投影”我认可，其他的我不确定）

| 项目      | 规定                                                                                   |
| ------- | ------------------------------------------------------------------------------------ |
| 调色板     | 全站统一 32 色，一次定稿，之后不新增颜色                                                               |
| 投影      | **只允许正面平视**（orthographic side view / flat front elevation）。全站不出现等距 45° 俯视（isometric） |
| 抗锯齿     | 关闭。像素边缘必须硬                                                                           |
| 抖动      | 只用 1 到 2 种固定抖动图案（dither pattern）                                                     |
| 光源      | 方向全站固定（建议左上）                                                                         |
| 背景分辨率   | 180×320（竖版，9:16）                                                                     |
| 设施 / 摊位 | 96×96                                                                                |
| 像素小人    | 24×24                                                                                |
| 图标      | 32×32                                                                                |
| 字体      | 中文像素字体一种、英文像素字体一种，全站不换                                                               |

**生成图片用的英文关键词：**

`pixel art, orthographic side view, flat front elevation, 32 color palette, no anti-aliasing, hard pixel edges, parallax layers, amusement park`

**前端实现方式：**

`image-rendering: pixelated` + 雪碧图（sprite sheet）+ CSS `steps()` 逐帧动画。

不需要复杂缓动曲线和阴影层次，审美控制权在图片资产上。

### 2.2 手势：全站只有竖向滚动

**不允许任何横向滑动翻页。**

手机端用户的默认动作是上下滑，加入横滑会造成体验割裂。

视角和竖滑不冲突，因为**往下滑就是往前走**（参照竖版卷轴游戏：画面往下卷，角色在往前飞）。

全站统一隐喻：**往下 = 深入**。

### 2.3 移动优先

手机端优先，桌面端同套资产适配。

- 出图时让 AI 出宽幅场景，再按 9:16 裁切（像素图分层拼合，裁切不伤画质）。
- **但构图必须按手机定稿**：主体居中，重要元素不靠左右两边。
- 桌面端做法：同一场景的宽幅版本，两侧露出更多景深。

### 2.4 园区天气（解决「乐园太甜会压平风格」的问题）--这个可以后续再做，太废token

电玩城的默认气质是亮、吵、甜。侘寂和极简放进去会变味。

解法：**网格、调色板、投影、光源规则全站统一，但每个园区（专题）的天气和时间不同。**

- 暗黑园区：雨夜
- 极简园区：雪天正午
- 水墨园区：晨雾

一致性由规格表保证，温度差异由天气承担。这同时也是延展性来源：乐园可以无限开新园区。

### 2.5 常驻导航与返回

**固定导航 + 面包屑并存。（尺寸不一定是32x32）**

屏幕角落常驻两个 32×32 像素图标（全站任何页面都在）：

| 图标  | 点击跳转           |
| --- | -------------- |
| 小地图 | P3 园区大道（全站总枢纽） |
| 票根本 | P6 兑奖柜台        |

此外每个二级以下页面顶部显示来路面包屑，例如：

`浏览区 › 忧郁园 › 哥特`

面包屑每一级可点，可逐级返回。

乐园里本来处处有指示牌，常驻导航不违和。

### 2.6 全站复用组件

开发时优先实现这三个，它们在多个页面出现。

**① 灯牌（风格词条的统一入口）**

```text
统一的像素灯牌外框（1 个资产，全站复用）
+ 风格名（像素字体，纯文字层，不画进图里）
+ 框内一张缩略图（从该风格已有的作品里切一张）
```

新增一个风格的美术成本为零：填一行数据、挂一张已有的图，灯牌自己就出来了。

**未完成的风格：**

灯牌不亮，暗着的，牌面写「即将开放 COMING SOON」，可挂脚手架。

乐园里这是正常景象，不是缺陷。Demo 上线时只有部分词条写完，其余灯牌暗着，画面反而更像真的乐园。

**② 票根**

用户乘坐过一个设施后掉出的一张像素票根。

- 正面：风格名。
- 背面：他认领的那句第一人称句。
- 收进 P6 票根本。

**③ 常驻导航条**

见 2.5。

## 4. 逐页分镜

| 项目     | 内容                                                                           |
| ------ | ---------------------------------------------------------------------------- |
| 画面     | 游乐园全景，正面平视，白天。三层视差：远景（天空、云、摩天轮上半截）／中景（过山车、海盗船、大门）／近景（摊位、地面、像素小人）。大门上方挂一句定调的话 |

| 数据来源   | 文案写死在页面，无数据库                                                                 |

### P4-B-2 · 单条线路（图谱的实际形态）

| 项目     | 内容                                                                                      |

| 动效     | 小火车位置绑定滚动进度；经过一站时站台灯牌亮起、火车鸣笛（可选音效）；到换乘站时支线轨道渐亮                                          |
| 素材     | 轨道段（直线段 + 弯道段 + 岔道段，共 3 个，拼接复用）、枕木纹理、小火车 sprite sheet、站台 1 个、灯牌组件（复用）                   |
| 用户能做什么 | 往下滑看这条感觉通向哪些风格、点灯牌进词条、在换乘站转到另一条感觉                                                       |
| 入口     | P4-B-1                                                                                  |
| 出口     | → P5；或转线留在 P4-B-2                                                                       |
| 返回     | 面包屑 `地图亭 › 我不想被看穿`                                                                      |
| 数据来源   | 飞书「风格词条表」的感觉标签字段反向聚合：某条感觉被 N 个词条挂到 = 该线路有 N 站。一个词条挂了 2 条以上感觉 = 它是换乘站                    |

**为什么不做 Force-directed Graph（力导向图）**

1. 手机上节点挤成一团，点不中也看不清标签。
2. 每次刷新布局都变，用户建立不起空间记忆，而「认识自己」这件事用户需要能再找回上次那个位置。
3. 它好看但不可读，用户看到的是一坨毛线，不是「我的感觉通向哪里」。
4. 它要求一次性具备完整全局关系数据。

**为什么也不做地铁线路图的样式**

拓扑结构借用（一条线串多个站、共用的站是换乘站），但 transit map 的平面设计语言（等宽粗线、45° 折角、无衬线字、临床感）和游乐园完全不搭，必须换成手绘风游乐园导览图：微黄纸面、弯曲轨道、枕木纹理、圆弧拐弯，全部像素绘制。

### P4-C-2 · 意象实验室

**这个功能的定位必须准确，容易被做错：**

它不是风格搜索器，不是心理测试，不是让 AI 根据用户输入生成图片，也不分析用户的性格或审美偏好，不打分。

它的作用是：通过改变两个意象之间的关系，制造新的创作命题，让用户发现原本没想到的画面和表达可能。

核心理念（可作为页面文案）：

> 有些新的画面，始于一个没有答案的式子。
> 观察 / 拆开 / 重组。
> 等号右边，留给你。

| 项目       | 内容                                                                                                                                                               |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 画面       | 机柜面板上三个大像素按钮（＋ － →），上方是屏幕，屏幕里是一个式子                                                                                                                               |
| 内容       | **三种意象运算**：＋ 相遇 Encounter：让两个原本没有直接联系的意象相遇。例「时钟 ＋ 发芽 ＝ ？」；－ 抽离 Subtraction：从熟悉的意象中拿走某种理所当然的属性。例「一座没有门的房子」；→ 替换 Replacement：让一种事物承担另一种事物的角色。例「如果记忆是一座房子，它会是什么样子？」 |
| 使用流程     | ① 选运算方式 → ② 选主题（或「全部」）→ ③ 获取意象（题库随机抽取**或自己输入**）→ ④ 系统生成开放式命题 → ⑤ 用户自己联想 → ⑥ 复制带走 / 存入票根本                                                                         |
| 功能       | 创意实验工具                                                                                                                                                           |
| 设计目的     | 「感觉配方读的是你已有的感觉，意象实验室造的是还不存在的感觉。」                                                                                                                                 |
| 动效       | 按钮按下有物理下沉感；式子在屏幕上逐字出现；抽题时意象轮盘滚动后停下                                                                                                                               |
| 素材       | 机柜面板 1 个、三个按钮、屏幕边框                                                                                                                                               |
| **视觉禁令** | **等号右边必须是一块真正的空白屏幕**，不得被任何像素装饰填满。用户在这里自己打字。这是全站唯一不该做花的地方                                                                                                         |
| 用户能做什么   | 选运算、抽题、自填意象、搜索、复制命题、存入票根本                                                                                                                                        |
| 入口       | P4-C                                                                                                                                                             |
| 出口       | **不回流**（出口是用户自己的脑子和剪贴板）。可存入 P6 票根本                                                                                                                               |
| 返回       | 面包屑回 P4-C                                                                                                                                                        |
| 数据来源     | 飞书「意象命题表」（约 70 条）。**注意：这 70 条是创作命题，不是 70 道测试题。** 题库动态读取飞书，不写死在页面                                                                                                 |

### P5 · 乘坐（词条详情页）

**101+ 个词条共用唯一一套模板。** 不做多套版式。

选「室内轨道游览车」作为模板原型（鬼屋、小小世界那类：坐上车沿一条轨道穿过一个个布景）。

它天生统一：

- 轨道只有一条，所以结构固定。
- 沿途是几个布景，所以章节清楚。
- 每个布景换的只是**灯光颜色 + 墙上挂什么**，骨架一动不动。
- 它本来的设定就是「你穿过别人的世界」，装暗黑能装，装侘寂也能装。
- 滚动条天然就是轨道，往下滑 = 车在往前开。

| 段               | 画面               | 内容                                      |
| --------------- | ---------------- | --------------------------------------- |
| **1 候车区**       | 一块告示牌，前方是黑洞洞的入口  | **大字 = 风格名**。**小字 = 第一人称句**（必须保留，见下方说明） |
| **2 入隧道**       | 一段纯色暗场，灯依次亮起，车启动 | 纯转场，不承担任何信息                             |
| **3 布景（数量不固定）** | 车窗外一个个布景板        | 每个布景 = 一段内容。见下方布景零件说明                   |
| **4 出站**        | 下车，票根掉出来         | 票根（风格名 + 第一人称句）+ 轨道分叉指向 2 到 3 个邻近风格     |

**布景零件（统一骨架，三种类型）**

每个布景不管是哪种类型，骨架完全一样：`一面墙 + 一盏灯 + 一段文字`。

|   |
| - |

**布景数量为什么不设上下限**

内容多少由案例决定，硬凑格式就是在编。

节奏感不来自「每页段数一样」，来自两件事：

1. 布景内部骨架完全一样，用户读到第三个布景就学会了怎么读。
2. 轨道进度条（见下）让用户知道自己读到哪里。

长短不齐不会被感知成「没规矩」，只会被感知成「这条内容多」。杂志就是这样：栏宽固定，篇幅随内容。

**案例极少的词条怎么办**

不加新模板。序列用「案例布景 ×1 + 对照布景 ×1 + 出站」，三站，不显空。

| 项目            | 内容                                                                                                                                          |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 功能            | 深入理解一种美学风格                                                                                                                                  |
| 必做组件：轨道进度条    | 页面右侧一条竖向的像素轨道缩略图，每个布景一个站点圆点，一辆小车图标随滚动往下走。它让用户随时知道还有几站，长词条不会读着发慌；同时是跳转导航，点圆点直接跳到那一站。**成本极低但不能省**，它是解决可变长度的关键零件                               |
| 动效            | 入隧道时灯逐盏亮起（steps）；每进入一个布景，该布景的灯光色渐变上来；作品图进入视口时从暗到亮；出站时票根掉落并飞入票根本图标                                                                           |
| 素材            | 隧道骨架约 6 张（候车区、拱门、空布景墙 ×1、出站口、轨道进度条组件、票根）。**全部 101+ 词条共用这一套**。拱门上的风格名用文字层叠加，不画进图里                                                            |
| 每个词条只需填 4 个变量 | ① **调色板**：隧道灯光、墙面、字色，从全站 32 色里挑 4 到 5 色（暗黑 = 墨黑/血红/骨白）；② **窗外作品**：挂在各布景墙上的 example 图 + 出处；③ **代表作品缩略图**：用于灯牌；④ **文案**：第一人称句、风格名、各段心理解读、邻近风格 |
| 气质差异全由调色板承担   | 同一条隧道，灯打成冷蓝雪白就是极简，打成灰褐晨雾就是水墨。「乐园太甜会压平侘寂」这个问题在这里由调色板解决，不用另做模板                                                                                |
| 用户能做什么        | 往下滑读完、点作品看原图、点进度条圆点跳转、点邻近风格去下一个词条、票根自动存入票根本                                                                                                 |
| 入口            | P4-A 灯牌墙 / 扭蛋机、P4-A-2 专题牌楼、P4-B-2 线路站台、P4-C-1 关联词条                                                                                          |
| 出口            | → 另一个 P5（邻近风格）                                                                                                                              |
| 返回            | 面包屑显示来路，例 `浏览区 › 忧郁园 › 哥特`；或常驻小地图图标                                                                                                         |
| 数据来源          | 飞书「风格词条表」                                                                                                                                   |

> **为什么候车区保留第一人称句小字**：从 P4-A 灯牌墙点进来的用户是点着风格名进来的，告示牌写风格名不违和。但从 P4-B 线路图进来的用户，他一路认领的是「我不想被看穿」，到了设施门口如果只剩风格名，整条感觉通路会断在最后一步。一行小字成本是零，两条路径共用同一块牌子，不用判断来源。

> **「名词出现在用户认领完自己之后」这条原则由谁承担**：由 P4-B 线路图（必须从感觉站点出发才摸到风格设施）和 P6 票根本（记的是句子不是名词）承担。P5 本身不负责，因为它的读者可能是从灯牌墙直接点名字进来的。
