# 可替换艺术层与数据接口

## 当前接通的艺术层

网页服务读取 `tools/layout-editor-v1/data/project.json` 的最新保存状态。编辑器内一个场景的 `artSlot` 对应网页的素材位置。网站使用编辑器本身的 `renderer.js`，没有另抄坐标或另写一个渲染器。

素材位：`p1-scene`、`p3-browse`、`p3-feelings`、`p3-arcade`、`p4a-balloons`、`p4a-gacha`、`chapter-gate`、`p4b-interior`。

尺寸由编辑器场景决定，手机读取 mobile，桌面读取 desktop；按容器等比显示。编辑器预览的缩放比例与浏览器中的容器比例可能不同，但原始元素几何、顺序和内容是一份数据。整数倍素材缩放不保证任意浏览器宽度下整幅画布的 CSS 缩放仍是整数倍，最终像素显示需再结合实际屏幕验收。

尚未接通：为艺术层内任意元素设置点击路由、动画轴／路径、P1 每个景深层的运动绑定、P5 动效图集。当前功能入口是独立 HTML，保证没有最终插画时仍可使用。

## 感觉数据入口

`data/experience.json` 的运行内容当前为空，禁止从旧形容词列表自动生成映射。

字段约定：

- `schema`: 固定 1。
- `feelings`: 数组；每项 `{id, sentence}`，sentence 为真实确认的第一人称句。
- `termFeelingIds`: 对象；键是既有真实词条记录 ID，值是感觉 ID 数组。
- `termStatements`: 对象；键是词条 ID，值是直接进入词条时的默认第一人称句。
- `questionsReviewed`: 旧问题文案完成 V2 审核后才置 true。

数据装入时检查感觉 ID 唯一性、关联词条存在性、关联感觉存在性。一个词条关联多个感觉，会在各线显示换乘。关联到未开放词条时，仍显示暗灯牌，不允许扭蛋或点击绕过开放状态。

本轮不在飞书建立新表或写任何记录；字段映射由后续内容整理明确。现有真实快照与新感觉数据保持分离。

## P5 内容接口

当前 `makeSections` 只读取词条 `core` 和 `caseIds` 对应的真实案例；案例展示原图、署名、`whyLong`／`why` 与官方出处。所有词条共用一套结构，可有任意数量的布景。

旧 `hook`／`body` 不作为 core 缺失时的替代。对照布景、第一人称句和邻近词条没有真实数据时不猜；默认不为凑两三个邻近风格而添加随机推荐。

## 状态与事件

| 行为 | 规则 |
| --- | --- |
| 初次进大道 | 发地图／票根本，约 2.6 秒后结束；可以跳过；用户开始滚动时停止自动带动 |
| 再次进大道 | 不重复欢迎段；普通返回恢复当前会话的滚动位置 |
| 扭蛋 | 动画期间禁用按钮；只抽已开放项；离页清理未完成计时器 |
| 出站收票 | 票根进入视口时记录；同词条去重；不把未选感觉的人自动标成认领 |
| 作品原图 | 点击／键盘进入；关闭按钮、Esc 或遮罩外部关闭 |
| 实验室 | 右侧答案为空白输入区；有联想时换题／运算先提示保留；切页草稿存本窗口；不打分、不回流词条 |
| 减少动态效果 | 关闭装饰动画；主要功能、跳转和收票仍可用 |

实际浏览器操作与动画节奏待验收，DOM 模拟只核验结构和处理逻辑。
