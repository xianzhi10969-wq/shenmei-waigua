# P4 教堂座椅 · 点击翻阅图册与单颗落星延续 v2（2026-10-23）

**状态：夕里在 2026-10-23 已认可 v1 中殿/长凳结构。本 v2 仅提出「座椅点开 → 长凳前的双页阅读图册」与「P3→P4 星 B 单颗延续」；新增动效、美术版面及星位均待夕里单独验收。**

路径：`web-prototypes/p4-nave-pews-v2-2026-10-23/`。该目录是**独立分支实验版**，不覆盖 v1、P3 彩窗 v3、P3/P4 v9、P1/P2 v4、飞书或 Figma。新增层为 `folio-layer` 和 `starBridge`；座椅 SVG 轮廓/教堂中殿空间比例维持 v1，仅将远端窗内临时的简化交叉星位标记替换为唯一真实语义的八角星 B。

## 如何看 / 操作

在仓库的 `web-prototypes/` 父目录下通过静态服务打开（有条件时，P3 v3 的现有静态彩窗素材会自动按相对路径引用）：

```bash
cd web-prototypes
python3 -m http.server 8765
# 浏览器 http://localhost:8765/p4-nave-pews-v2-2026-10-23/
# 直接进入 P4 http://localhost:8765/p4-nave-pews-v2-2026-10-23/?inside=1&topic=eros
```

桌面/手机均可操作：进入教堂 → 点击第 1–8 席中任何长凳 → 图册由点击席位的位置展开 → 翻上一席/下一席 → 合起回到同一张长凳。按 Escape 也可合起。24 个专题切换继续继承 v1 的下拉列表与 `?topic=slug`。没有真实数据时，8 个席位仅为结构容纳演示；有只读数据时按原 v1 `window.P4_TERMS_BY_TOPIC` 的记录加载真实名称、说明、封面 URL（`cover_url`）及经核验的 `v3_url`。

## 点击前后分镜

1. **P3 彩窗（既有版本）**：用户选中某个一级专题。星 B 已在玫瑰窗所在轴线上。v2 的入口画面只是引用原有 P3 图片；没有替换/重做 P3 的 24 题系统。
2. **进入 P4**：原窗在中殿远端重新获得空间关系，镜头拉开，留下中央通道与两列长凳；`starBridge` 是整个原型的**唯一一颗可点星**，采用 v4/P3 的四长四短八角星轮廓语义，黑米白双色，不加入每席小星星。这里只验证独立动线，未实现 P2→P3 / P3→P4 的生产态滚动同步与逐像素空间配准。
3. **轻点长凳**：选中靠背变黑；镜头轻微移动，双开页阅览册从所点席位的屏幕位置缩小→展开，持续约 700ms（手机约 560ms）；无弹跳、无阴影、无背景蒙灰。教堂上半部可见，用户知道自己仍在座椅场景。
4. **阅读图册**：左页保留词条原画画心；右页放飞书只读标题、正文摘要与实际 V3 详情链接。没有数据时全部明确标为「示意/待接入」，**不编造细分词条**。上一席/下一席在同一本图册内翻阅，不能变成电商瀑布流。
5. **返回**：合起图册回到刚刚选中的长凳；回到 P3 时仍保留当前专题。减少动态效果的用户直接切换终态。
6. **星星点击**：保留一个真实可点击的入口，当前仅显示接线说明；**不重画/假装做完**另一个任务的 Le Pater 五徽章索引（此前只确认了布局，未确认其余美术）。后续全站整合时应由主导航控制器接管星星组件，而不是每页一颗。

## 数据 / 边界

- 一级章节：24 个名称顺序沿用 P3 v3 的飞书只读快照。
- 细分词条：飞书「词条」表，按「所属章节」关联章节，依「章内序号」排序。**本轮没有读取完整词条表、没有接真实词条封面、没有核验 V3 路由**；所以实例全部使用编号占位。原 v1 注入适配接口不变。
- 两色：`#F6F3ED` / `#1E1E1E`。词条原画未来可在图册左页限定范围内使用原色；当前画心只是空白结构示意，不新绘任何插画。
- 不使用渐变、阴影、噪点、金色、灰色排线或新装饰徽章。星 B 沿用既有轮廓语义，v2 SVG 是前端结构引用实现而非替换 v4 像素资产。
- CSS / JS 只新增选中阅读图层、星星桥接与镜头微移；P3 彩窗原素材不改，v1 的中殿外框/座椅点位未重排。

## 自检与已知问题

- 2026-10-23 以 Chromium + Playwright 测试桌面 1440×900 / 手机 390×844：进入中殿、选第 3 席、展示图册、下一席、合起、点击星星、切换专题；浏览器脚本异常为 0。截图 `state-nave-*`、`state-open-*` 为这个测试产生的预览。
- **待验收 1**：点击后图册是否应该留在场景中，而非接成新的完整词条页面？v2 选择「位于场景中的阅读器」，以保留教堂上下文。
- **待验收 2**：手机屏幕打开图册时只保留上部的玫瑰窗与拱顶，长凳被前景图册遮住；是有意的近景切换，但需确认是否愿意让中殿座椅短暂退出画面。
- **待验收 3**：星从 P3 走到 P4 远端玫瑰窗的动画，只验证大致轨迹；**没有实现原 P3 彩窗生产版真实像素锚点对齐/双向滚动驱动**。原 P3 图可能自带星星像素，正式整合时必须做单组件所有权/原图去星，否则可能出现视觉重复。
- **待验收 4**：仅键盘操作/Chrome 浏览器模拟；实际触控/读屏/设备性能待测。长凳内容占位 8 个，非飞书真实数量。
