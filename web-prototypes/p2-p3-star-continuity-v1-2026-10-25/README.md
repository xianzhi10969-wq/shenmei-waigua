# P2 → P3 星星接续 v1 · 当前最新 P3

2026-10-25。用户在完成第8节翻页＋刻度后明确要求继续补星星。状态：用户已指定为当前最新 P3；Web 已实现，待用户单独审阅桌面效果。详见 [当前 P3 登记](../../CURRENT_P3.md)。

本轮以用户当前正在看的 cut-paper-v1 为运动底版，只增加星星前景运动层。未覆盖 paper-rise 原型、P1/P2 v4、P3图录或刻度版本。

## 行为
水面星B从原水面位置升起，沿连续路径接近P3玫瑰窗中心。纸经过星时，同一星图的米色/墨色版本按纸上沿硬边分割；没有添加发光或阴影。最后旅行星收小至窗心、隐藏，保留原画已有的玫瑰窗星形。倒滚完全按同一进度返回。

这是一版“旅行星收进原窗心”的候选，不是把两种不同星形重画成一个；接近阶段会短暂看到旅行星与原窗星同时存在，是否需要进一步做轮廓交接待用户审阅。原图、蒙版、封面原色、题签和纸页原节奏均未改变。

## 运行
从仓库根目录启动静态服务，打开本目录 `review.html?device=mobile` / `review.html?device=desktop`，点击“往返预览”。依赖相邻 v4 和 p3-stained-glass-v3 的原夜景与星B素材，需从完整仓库根目录运行。没有与刻度新版本合并。
