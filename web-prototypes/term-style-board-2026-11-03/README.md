## 预览与编辑

在本目录运行 `python3 -m http.server 8000 --bind 127.0.0.1`，打开 http://127.0.0.1:8000/ 。也可整体下载目录后打开index.html。显示所需图片和字体全部本地提供，无需登录飞书或访问CDN。

- index.html / styles.css / app.js：完整第三版、可编辑字体与双端定位、编号打开来源逻辑。
- mobile.html：390px预览；type-study.html：字体细节对照；frames.html：无框/单框/双框研究。
- assets/images：10个图像单元的原像素派生图；assets/originals：使用的7张原图；assets/fonts及licenses：字体子集与授权。
- data/content.json：实际展示字段；data/units.json：词条、裁片、原图与案例的稳定ID映射；data/assets.json：资源散列；data/status.json：认可与未决状态。
- audit：裁切、布局、字体资源和验证；previews：双端整板PNG。

原20MB单文件已拆成HTML/CSS/JS/本地资源。没有改动原图、配色或裁片几何位置。字体仅从内嵌改为本地文件。原一、二、三版及黑框研究原文件均保留在本机；不声称本目录已包含全部历史工程。
