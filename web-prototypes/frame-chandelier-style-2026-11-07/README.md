## 为什么这样改

原框依靠多重细轮廓形成纹样，吊灯则以暖白实体、细轮廓和局部排线表现转折。新框把卷叶和长边变为有暖白留面的窄构件，将刻线集中在转折与角花。生成一幅完整边框也能处理原横框九切片在右侧角花处的接缝。

这张候选的灰阶层次比原框更明显，体积感是否合适、是否与吊灯同一画风，仍由用户看页面判断。
