# 桌面画幅修复 v2 · 待审

2026-10-25 用户指出上一版桌面画幅错误。原星星版桌面 CSS 将 945:995 五窗图放大至整个内容宽度，使画高超过视口，首屏仅见拱顶。上一轮“Web已完成”判断撤回。

独立修复：按可用高度等比容纳完整五窗及题签，保留翻阅入口。原图、蒙版、星星运动函数、手机版均未改。不是新绘横幅，不拉伸窗框。当前最新指针仍指星星v1；v2待用户看图，不自动升级。

## 版式规则证据
读取项目 Editorial Skill，以及上游 grid-construction.md / page-composition.md（medoismail/grid-systems-editorial-skill）。
- E02：先固定桌面视口，再预留180px给页眉/翻阅/说明，画宽=min(内容宽,(视口高−180)*945/995)。拒绝以全宽倒推无限画高。
- E05：完整五窗与题签作为视觉主体，原画等比缩放，不裁掉内容；不以强行拉宽消除留白。
实现为独立 desktop-fit.css，仅作用于681px以上；Figma未修改。手机规则保持相同。

补查根因：review 的 desktop 参数原先仅影响按钮，iframe随面板宽度触发680px手机断点。现桌面固定1440×900、手机固定390×844，外层等比缩放。浏览器已看到桌面五窗完整画面，截图 checks/desktop-fixed.png 仅本地。
