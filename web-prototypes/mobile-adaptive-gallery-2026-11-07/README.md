## 本轮改变

1. **图片决定框高**：使用每张原图的真实宽高。内衬每边3px、素框每边9px，宽高按原比例联动；不裁画、不填充上下大片空白。竖图在手机上为可用宽度的80%，横图可占完整画面宽度。源文件小于显示区时不任意放大到满宽。
2. **词条身份在画前，作品署名在画后**：数字、词条名/英文、原有“在本章的位置”引导观看；画后呈现可核对的作品图注与真实案例数量。没有把词条名称误当画作标题。
3. **内容组织展线**：田园沿用后台顺序和原文——树荫、树荫下的小屋、太阳底下。其他章节沿用既有顺序；幽玄保留现行特例。不以框型轮换强行改变内容顺序。
4. **手机装饰**：本结构稿撤掉截断的柱子、檐口和纸纹，先核验图文空间。未来绘制的装饰有明确依附物：画框。没有凭代码新造艺术花饰。
5. **黑白灰可比较**：三色目前是中性素框技术试样。田园依次白/灰/黑作为候选；其他封面用平均明度初配，仍需要策展人工选择，不宣称自动配色已成立。原图不加滤镜。
6. **全量数据而非单图演示**：24章101词条；46张封面，55条暂无封面。无图词条显示简洁文字；已上线仍有真实阅读入口，不画空框冒充作品。

## 自适应雕花的实现边界

尺寸计算难度较低，批量套用可行。真正的美术工作是建立可伸缩素材系统：固定四角、固定中央纹章、可延长的直边、独立内衬。整张华丽画框用拉伸或不分结构的九宫格会扭曲角花或产生接缝。本轮 `frame-construction.svg` 只说明组件几何，尚未绘制这些花饰；上一轮新横框也没有直接切碎或覆盖。

三种框色应各自控制底色、线色和明暗，不能靠整幅反相。框高变动时保留角花尺寸与线条密度；极窄长图需要小角花或窄边版本。这些仍须单件绘制与审图。当前白底、中性字体与素框不代表最终画风或字体选择。

## 验证与保护

verify.py 在320/390/430/1440宽下检查24章，共96个页面尺寸组合：无横溢出；图像比例误差小于1px；每侧框边与内衬保持12px；无脚本/HTTP错误。真实点击核验原图关闭、框色切换、章内滚动、回顶部、词条入口与浏览器返回；另检查图片失败状态。checks.json 有记录。已查看田园手机全页、三件局部和桌面截图。
