- 手机拖杆预览 `http://127.0.0.1:8765/web-prototypes/p2-p3-junction-v2-2026-10-23/review.html?device=mobile`

拖动上方进度条、按「回到水面 / 进入彩窗」，或在镜头获得焦点后使用 Home、End、PageUp、PageDown、上下方向键。进入完成后继续保留一格一格的专题浏览。`?at=0.3` 只定位真实滚动进度，不是替换画面的测试假状态。`?lineonly=1` 单看 P3。
