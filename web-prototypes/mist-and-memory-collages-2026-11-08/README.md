## 这一轮做了什么

复古把装饰书页、饭店粉色中庭、礼宾台、甜点盒子和旧日人物错层叠放。朦胧让栈桥、夜雾、人影、雨线与月下扇面相互遮叠。盐系以地平线铺底，加入《うたたね》的书页和白裙人物真实轮廓。法式不经意将午宴露台、餐桌、草帽、小狗和街头长裙穿插，以黑白人物形成主要前景。

桌面1200×1100、手机390×1110各自构图，先输出可编辑黑线结构，再生成实际图层。独立候选目录保存源图、坐标、取景和显示层。标题、白纸与字体延续既有方向。整站词条继续以core正文开场，本批接入既有拼贴入口。

## 真实素材与取景

4张来自当前后台已有附件，22张从同一现有案例的馆方、作者、出品方或设计师作品档案补图。原图文件SHA256、案例ID、附件身份及下载URL均在sources.json，10个案例的现有内容在case-snapshot.json。沿用已经核验的词条rev239／案例rev420只读快照，本轮没有实时读取飞书。

- 乔叟沿用现有600×867扫描图，局部放大时细节较软。芝加哥艺术博物馆的补充IIIF图片未取得，因此只采用已有这一页。
- 布达佩斯大饭店采用Searchlight官方电影页的海报及剧照，出版权利归原权利人。多张剧照由原站780px图片放大至2000px，文件尺寸不代表原生细节。
- 月下赏梅图采用大都会艺术博物馆1796×1678完整原图，Public Domain。
- 模糊建筑采用Diller Scofidio + Renfro官方项目页的真实建筑照片。
- 辛崎之松沿用此案例已有的广重《唐崎夜雨》图。它是后台案例所用的视觉材料，作者关系保留在案例正文。
- MUJI《地平线》从AGI所载原研哉本人作品档案补入。原后台MUJI链接当前处于维护页，原研哉旧站访问失败。
- 《うたたね》采用川内伦子官网的5张封面与跨页图，图版中裁去部分拍摄背景，点开仍是完整书页照片。白色交响曲第一号沿用现有附件。
- 船上的午宴沿用现有菲利普斯收藏馆图像，布洛涅森林大道采用MoMA所载1911年同一幅照片。后者版权归Association des Amis de Jacques Henri Lartigue及原权利人。

白裙与街头人物的前景使用macOS Vision提取真实像素轮廓，透明PNG是显示衍生层，完整原图各自保存。显示层最长边1100px，双端SVG保持源图坐标关系。普通重建直接使用已包含的显示层，无需再次抠图。
