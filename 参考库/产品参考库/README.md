## C. 当前 P1–P4 使用边界
- **P1 / P2**：延续已定黑白钢笔线描世界；P2 小面积色彩和状态转换不因参考库改变；不准借网站图案直接覆盖原线稿。
- **P3 / P4**：参考 Emergence 的“进入世界”、Cosmos 的“收藏与探索”，但不以新参考直接重制已回退确认的 P3–P4。专题选中态、图录切换属于独立交互设计。
- **字体与构图**：参考 OSP、Readymag 的字图共生，避免默认字体＋常规 PPT 分栏；图片不能被 CSS 假线描取代。
- **手机端**：以独立重构为准，不能仅把 Web 截图缩放。
