## 存档规则
1. 先按**研究目的**分类，而不是按平台分类。某网站若主要研究界面/动效，归产品；若研究获客/商业转化，归流量。
2. 一条参考记录至少包含真实来源链接、要学习的具体机制、适用页面/环节、验证状态。不能把参考当作已通过的设计决策。
3. 原有档案不删除、不搬动、不覆盖。旧 `对标/notes/` 仍是流量案例的真实文件位置；本参考库提供独立索引并注明来源。
4. 产品参考不等于可直接使用的美术素材，未经确认不得照搬他站图案、角色、布局或用作本站上线资源；实施稿应另行验证。
5. 用户已确认的 P1/P2、P3/P4 版本及视觉红线以 [CURRENT_STATE](../CURRENT_STATE.md) 和现有决策文档为准，参考库不能推翻它们。
