## 分类原则
- **流量案例**：小红书封面、内容形式、搜索词、账号矩阵、付费资料、转化漏斗、定价和销量证据。
- **产品案例**：网页视觉世界、字体、动效、交互反馈、信息架构、手机端体验。请放入[产品参考库](../产品参考库/README.md)。
- 同一主体可能同时有流量和产品价值，但应分别写清**为什么参考**，用互链关联，而不是复制素材到两个库。
- 竞品笔记里的销量、粉丝、价格以及交互数据须保留来源日期，不能默认今天仍然准确。

## 后续新增的最低字段
平台／作者、原始 URL、截图或配图所在位置、采集日期、内容钩子、流量机制、转化机制、可借鉴点、验证状态。
