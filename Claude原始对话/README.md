# 审美外挂：恢复的 Claude 对话

本目录收录从本机恢复出的、与「审美外挂」（原「感觉词典」）项目相关的 Claude 对话。仓库为 Private。

- `Claude网页_项目起源_用户保存原文.md`：用户另存的一段长篇网页对话，包含项目从虚拟资料选品到感觉词典的形成过程。它是保存下来的对话文本，并非 Claude 官方导出。
- `ClaudeCode_*_原始记录.jsonl`：两段 Claude Code 本地原始会话日志；同名 `可读对话.md` 便于阅读。两段记录有部分共同历史，请勿简单相加当作独立对话数。
- `可能关联_飞书搭建_*`：一段讨论飞书搭建效率的短会话，关联性尚待确认，因此单独标注。
- `Claude网页_*索引*.csv`：网页端 10 条项目会话及 2 条更早可能关联会话的标题、时间、ID。**本机没有恢复到这些会话的正文**，索引不能当作完整聊天。

原始 JSONL 可能含工具调用、附件信息和本机路径；阅读项目讨论可先看 Markdown。
