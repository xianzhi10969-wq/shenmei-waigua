# 101条概念复核｜取消强制二分

2026-11-09用户纠正后的候选。style只计入有外部具名风格/美学讨论支持的条目。mood包含可跨风格出现的情绪、身体感觉与感官氛围。对象、题材、季节、事件、媒介、工艺、叙事类型允许归other。范围或证据不足暂列pending，未检出证据不等于不存在。

101个原ID保留为盘点来源，不再要求101项全部生成mood/style页面。可新增真正需要的感觉或具名风格，候选分别审阅。名称要在概念身份收口后重做，旧101白话名和179条关联暂停沿用。

诡异、恐惧、燥热、悸动列为新增感觉候选，未自动成为词表同义词或正式标签。所有具体感觉关联都是待审编辑建议。
