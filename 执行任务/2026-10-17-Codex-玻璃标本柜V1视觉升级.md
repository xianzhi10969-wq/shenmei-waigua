- 主画面是浅米灰背景，柜体全身是很淡的**薄荷灰绿**，大量均匀的浅线条；六格结构虽正确，但与 G17 的识别度弱关联。

## 二、下一个最小可验证成果

**不是重画六格正式内容**，而是在现有程序旁安全地做出 **V1 视觉方向实测版**：
- 保留现有六格结构和已经工作的交互状态，不重写成 6 张卡片。
- **让精密玻璃展柜成为站在“审美外挂”视觉舞台上的艺术物件**：页面外部可以借鉴黑色植物雕版/暖纸面/像素字标/暗红点睛；柜体本身仍应保留医疗档案柜式精密、透明、冷金属的独立气质。**不强行在每个玻璃门上贴花纹**、不把 G17 原框直接复制套在六个格室上。
- 先做颜色/材料/比例/光影的层级关系；只要黑白灰对比与视觉焦点还不成立，就不要开始增加花纹/小图标。
- V1 只给**一个格室**做“标本摆放密度与构成测试”：至少体现“一个主视觉原型 + 少量辅助手法/材质/形状线索 + 大小与留白”，不必命名美学。**标本不是艺术案例、不是 Pinterest 卡片，也不是用 CSS 假装高艺术质量的复杂画作**。若现有项目里已有被用户认可且有合法来源的独立艺术资产，可在实验中引用；若没有，使用醒目标注的纯结构性占位及少量测试物件，勿自行下载未授权艺术作品充当成品。其余五格保留结构但不必重复内容。
- 单格打开后改变为**近距离观察标本与其空间关系**；不应只复制一个更小的空柜放到大弹窗正中。可用原代码的详情状态与焦点管理，保留退出/切换功能。

## 三、建议的视觉施工次序（不可跳层）

1. **准备与保护**：确认真实项目路径、当前分支、未提交改动、AGENTS；在 V0 旁新建独立的 V1 预览入口或安全分支，**保留 V0 可随时切回**；不修改线上正式首页。
2. **画面结构**：设计在一个屏幕中的柜体比例、留白与视觉重心。优先保证柜子“有份量”，不被标题和大片空白压扁。
3. **品牌视觉连接**：引入 G17 的有限视觉基因：黑/奶油色的体量关系、像素品牌名、局部暗红、小型档案标注。使用既有经过许可且可用的资源；不可拿 CSS 粗略模仿植物雕花线描。
4. **柜体材料**：以中性金属与真正透明的玻璃层次替换过度统一的浅绿色“塑料感”；反射应能看见但非常克制；搁板增加细微的前后/边缘厚度。不要赛博霓虹、毛玻璃 UI 卡片或厚重拟物花纹。
5. **一个格室的标本密度实验**：比较“空柜”与“一个有内容格室”，判断尺寸、层架和观看距离是否足够；复杂原创艺术标本以后由独立图片创作流程供应，不在此轮批量生成六套。
6. **近看交互镜头**：保留旧点击/退出逻辑，把模态窗或详情视角重心由缩小空柜改成格室内部；文字作为小比例解释，不让大白面板抢占视觉焦点。
7. **真实运行与对照**：1440×900、390×844 截图；V0 和 V1 并排截图；核验点击、下一格、Esc、焦点、reduced-motion、手机横向浏览。
