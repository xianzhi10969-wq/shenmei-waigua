## 1. 错误复盘（不是下一轮继续做的事）

上一轮错误任务书同时要求“提升艺术完成度”和“原四句、布局、构图、色彩、外框完全不变；不加任何新素材；只能动字号、行距、标点和编号”。Codex 如实得到 A1 和 A0 **肉眼几乎一致**的结果。旧任务作为微观排印练习完结，**不再继续精修，不算首页的艺术升级**。

当前用户要的是：**从根本上提升像艺术家/实验平面设计工作室那样的网页艺术表现**，摆脱 CSS 边框+文字、普通 PPT 式拼贴的粗糙感；需要研究图文关系、专门创作必要的网页素材、反复做视觉构成，而不是单纯调整字体。

## 2. 正确保留的是原则，不是每个像素

**继承的优秀基线**：[Figma Fork B P1 A · 印刷式多声部](https://www.figma.com/design/pIL4mlWLHxph3pqXlIVq1s?node-id=196-960)，同看 G17 仅其[植物雕版边框](https://www.figma.com/design/pIL4mlWLHxph3pqXlIVq1s?node-id=144-4)。

这些特性须保留：
- **体验**：读者认出自己的“有感觉，却说不出是哪一种美”的困惑；感受先于专业术语，像懂普通人的朋友。
- **结构**：四种平权人声，阅读有停顿，纸面留白承担呼吸；外圈花框承担高密度美学，内页不堆四个强视觉焦点。
- **品牌识别**：用真实的 G17 原雕花素材、像素字标、暖色纸面、黑与少量深红，但各元素可以重新编排，只要不覆盖母版。

**允许设计师真实发挥的范围**：
- 内页的区域关系、元素尺度、文字和图像的融合方式、文字变换与阅读路径、细部“如何从感受到命名”的概念视觉表现。
- 可以**新增原创且与主题紧密相关的视觉资产**（扫描/笔触/雕版/视觉化的字形/图解关系等），尺寸与位置通过真实画面效果决定；不能因为历史上禁止“随意装饰”就理解成任何图像都不能做。
- 可以试 1 个真正有主题含义的艺术视觉动作，其存在理由必须能解释：**为什么只适合“有感觉却叫不出名字”的首页，而不是任何商业网站**。
- A 原稿仍是可恢复的比较基准，**不要把 A 当作只能原像素复刻的最终母版**。

## 3. 这轮必须产生实物的创造流程（不要再提交研究报告）

### 阶段 I：提出一条具体创作假设（非常短）
用 100–180 字提出“内页怎么变得富有艺术感而不压住四句”的**一个**视觉构成动作。给一句可视化解释，并列出用到的原创素材和它在画面中的位置/作用。先直接开工，不用用户审批每个操作。

可作为思考起点、**不作为必须照做的指定成品**：
- 把“感觉尚未有名字”转为可视的**字形/缺字/无法归档的注释关系**：文字本身带有尚未命名的留白或对照；不同人声通过微妙的图解关联，最后才汇向命名入口。
- 让 G17 的“植物雕版”与内部“数字像素编目”发生一种**有语义的张力**：不是画更多藤蔓，也不是巨型问号/图层叠加，而是模拟两种观察世界方式的交接。
- 这两个思路只是方向，不是新 UI 功能，不要求制作两种版本。

### 阶段 II：先做素材，而不是一口气写整页代码
根据上述构想，产出 **1–2 件独立、可复用、可解释其作用的艺术素材**（SVG/透明 PNG/WebP/可编辑字形，视媒介决定），保存到隔离实验目录 `assets/`。必须是真正视觉创作，不是 12 根 CSS 线条、单纯灰框或 AI 随机附加老纸纹。

- 可以使用**实际可用**的图像生成/矢量工具或现有经过授权的品牌原始矢量，按工具能力选择。
- 不要凭空说已经 AI 生图；如果你的环境没有图像生成能力，优先检查现有允许调用的图像/设计工具；如果仍不可用，可以用**自主设计的非平庸矢量图形/字形构件**作为材质原型，或向本对话提交明确的独立图像制作请求、图层规格和透明导出标准。**不可拿粗糙 CSS 假素材伪称“已完成的艺术图像”。**
- 独立资产要有正当“内容关系”：说明它为何能让读者理解某条心声或“感觉→语言”的关系，而不是凭装饰材料冒充美术完成度。

### 阶段 III：以 A 的有效骨架重做一份有显著差异的网页视觉稿
- 在隔离目录 **真正构成一张新版 P1**，注意“视觉显著性”：同样缩略到 1128px 宽，第一眼可以感到**图文关系、艺术构成或专属素材发生实质变化**，但仍然舒适、没有失去 A 的安静与多声部。
- 文字内容保留真实用户痛点，但可以调整文案微层级、版面占比、视觉阅读顺序；**不要新增多个大标题、红横幅、巨型符号、倾斜贴纸或无意义照片**。大胆的概念可以精确发生在一处，其余保持克制。
- HTML/CSS 负责文字、布局、响应式、交互；决定艺术气质的复杂素材使用独立资产。可先以静态可访问实验页交付，不需要把本轮变成全功能 P2。
- 给桌面 (1440×900) 与手机 (390×844) 两种真实浏览器渲染画面。手机不应缩小整幅带框海报导致文字不可读。
- 保留历史 A0、A1 与暂停的柜体，不复用之前用户拒绝的三版 (Figma 205:2 / 205:1359 / 205:2716) 的显著视觉套路。

### 阶段 IV：设计师自我批评与一次实质迭代
在完成第一个可见稿后，**打开页面截图**并从“像 PPT 吗？”“内页有没有真正的艺术表现？”“新增素材与四段心声有没有关系？”三个问题批评它。自己至少针对**一个实质的视觉缺陷**再修改一次，保留前后截图。不要只是调整一个像素然后自称迭代。

## 5. 视觉验收标尺

- 用户**缩小观看前后两版**能明显认出 A2 是经过独立视觉创作的作品，而不是微调排版的 A1；
- 又不会像被否定的海报/贴纸/PPT 方案那样堆多个竞争焦点；
- 第一次观看的普通人仍能读懂“你对美有感觉，却未必知道它叫什么”；
- 外部 G17 植物雕版与内页表达有关系，真实文字仍可访问；
