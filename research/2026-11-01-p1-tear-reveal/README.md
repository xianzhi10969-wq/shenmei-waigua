# P1 泪滴从无到有 · 单次显现候选，待用户审阅

用户请求：原画眼下的泪滴也做从无到有，“但是只展现一次，总不能重复流泪”。

## 预览与实现

- 通过仓库根静态服务器打开本目录 index.html。左侧完整手机P1、右侧同步眼部局部；只有主动点击“重播这一次开场”或重新加载页面才重新播放。
- scene.html 是独立P1页面副本，引用现有发布素材和已采用星星明灭脚本；tear-once.js 仅在此研究页加载，未接入正式源目录/部署目录。
- 使用原图泪滴的像素，人物显影时先隐藏这一小块；人物显影完成后等待280ms，泪滴通过1100ms透明度＋向下揭示出现，iterations=1。
- 隐藏阶段的局部肤色取自原图相邻皮肤区域，柔化边缘；不另画眼睛或泪滴，不改原PNG。播放完成移除覆盖层，完整原图直接保留。
- 若人物显影被提前滚动结束，仍等眼部回到视野后开始一次；完成后滚动、离开视野再回来都不重播。
- 减少动态效果时直接保留原图。

## 验证

Chrome本地390×844、430×932共12项检查通过：人物显影时先隐藏泪滴、出现过程有透明度和向下揭示、启动次数=1、完成后覆盖层移除、来回滚动不重播、字标与既有星星明灭保留。复查入口 checks.html。

已看眼部放大画面，初始不露生硬浅色椭圆，结束恢复原泪滴。真实手机Safari未测，新动效视觉仍待用户审阅。
