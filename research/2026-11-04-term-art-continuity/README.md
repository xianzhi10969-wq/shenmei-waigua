# 词条美术接续研究 · 2026-11-04

状态：研究候选，未获结构或美术验收。保留旧词条、P1/P2 与 Coquette 第三版；未修改 Figma、生产站或飞书，未生成新插画。

## 这次判断的起点

用户明确：“原来的词条的风格设计我是满意的，只不过后来我又加上了 P1、P2 的美术观，所以两个美术风格打架了。”因此，先前“让拼贴取代旧词条开场”的建议撤回。历史 `term-continuity-study-2026-11-04` 草图不作为当前推荐；主库拼贴包 INTEGRATION-NOTES 中“作为视觉开场”也只是旧建议，不是用户决议。

本轮要解决的是两种已喜欢的美术如何共存，以及新拼贴放在哪里。不能把“统一”直接解释为删掉雕花、曲线、深色底，或把全部页面改成 P1 的建筑线描。

## 看过实图后的判断

P1 是有透视的线描场景：细线、修长主体、纸面留白。P2 进入深色空间，以阶梯、水面和星控制视线。旧词条则是平面编排：巨大的雕刻画框、跨出边界的书写曲线、大标题和原色作品。Coquette 拼贴又是第三种观看方式：在浅底上自由放置人物、衣物、细节与摄影，靠大小和距离建立联系。

冲突主要在于**从场景观看突然切到高密度装饰，再切到自由拼贴，缺少明确的阅读层次**。仅加一次淡入淡出，无法证明这种关系成立。

它们也已有共同点：大字、偏置的竖向主体、越出画面的装饰，以及原色艺术作品与有限背景色的并置。这些可以成为接续的依据，不必另画一套折中的装饰。

推荐研究叙事：**在空间中选中藏品 → 看词条扉页 → 展开风格图版 → 阅读作品与解释。** 这不是新增四个页面，而是明确既有页面内各段的职责。

## A：保留完整词条开场，拼贴作为下一张图版（优先验证）

1. 从 P4 选中词条，延续同一词名、封面与所属专题身份；返回时恢复原来的选择和位置。P4 当前美术仍需按其独立验收记录处理，不能把待审画框候选当作定稿。
2. 原词条开场保留深底、雕花、曲线和大字的组合。它承担情绪与身份，不承载整篇解释。
3. 下滑进入完整的拼贴图版。用共同的内容边距、图版标记和阅读方向形成关系；不在每件拼贴素材外再套一个雕花框。
4. 接回原有导言、完整作品及同页分析。拼贴里已出现的核心句，不在紧接着的导言中原样重复。

这里共享的是排版秩序；空间线描、雕刻扉页、原色拼贴仍各自保留。具体字体、色值、边距尚未提取锁定，不能把本轮示意字当作新字体方案。内容原图也不统一染色、做旧。

最大风险是“两个很长的开场”拖慢阅读。处理方向：扉页提供“看图版 / 看作品”的直接入口；手机自然滚动，不强制停屏，不把拼贴缩成一张不可辨认的缩略图。现有手机拼贴本来是 390×1260，超过一个屏幕。首屏到图版、图版到第一案例的距离应在同一条真实词条上实测后再决定，不能凭结构图宣布解决。

## B：桌面左右并置（比较项）

左侧原扉页，右侧完整拼贴，可以更早看到拼贴，但会同时出现两个视觉中心。原词条开场需要专门适配窄幅，不能把原截图简单缩小塞入；这会增加对已喜欢构图的改动。手机仍须上下展开。因此 B 保留为对照，当前更推荐先验证 A。

结构图：[可编辑黑线 SVG](structure-options.svg)。本地另有 `structure-options.svg.png` 预览和 `evidence.svg.png` 原图比较板。方框代表内容段落，不代表所有段落强制一屏。

## 拼贴怎样接入现有内容

Figma 现有阅读系统已经包括：开场 → 导言 → 同页作品与分析 → 灵感搜索词；作品预览 → 全部图片 → 沉浸大图 → 返回原阅读位置。应保留这条链，不因历史代码中存在案例路由就强制拆成多个页面。

Coquette 第三版有 **10 个图像单元、7 张来源图、3 条关联案例**，不是十个案例。02/05/08 对应 Gaultier；03/04/06/07 对应 Sandy Liang；09/10 对应 Juno Calypso。图上编号可作为同页案例的定位入口，再由案例进入现有图库。01 秋千图来自词条封面，没有关联案例，应打开原图及来源信息，不能编造案例页。

## 美术史线索与适用范围

Met 的 [Playing with Pictures: The Art of Victorian Photocollage](https://www.metmuseum.org/exhibitions/listings/2010/victorian-photocollage/photo-gallery) 及其[介绍文章](https://www.metmuseum.org/ja/perspectives/playing-with-pictures)记录了私人相册中的摄影剪贴与水彩组合。这给“维多利亚空间 → 私人收藏图版”提供了一条值得研究的文化联系。

本轮阅读的是文字资料，不声称成功查看全部展览图片。这条线索支持空间与拼贴能够具有共同语境，不等于已找到适合直接复制的样式，更不能据此给 Coquette 强加古旧滤镜。Side Gallery 的单张可访问相册图也不足以证明我们的构图，未采用。

## 下一轮只验证一个切片

变量：原词条扉页与拼贴的顺序、接缝和阅读距离。优先 A，B 只作比较。先审本轮结构，再做同一真实词条的独立双端试排；新增艺术素材仍逐件审图，不覆盖原稿。

交付与验收：

- 能认出原词条开场，用户喜欢的雕花、曲线和大字关系没有被“统一”掉。
- 从选中词条到扉页、图版，始终知道自己在看哪一条内容；P4 未验收美术不被顺带锁定。
- 桌面和手机都能细看拼贴；不缩成缩略图，不把两套主视觉强塞同一屏。
- 拼贴编号对应真实案例；无案例的封面有合理来源入口，图库关闭后不丢位置。
- 不重复整段核心句；能直接到图版或作品。先看静态接缝是否成立，再讨论动效。
