# 用户提出的新顺序：吊灯＋slogan → 拼贴 → 词条

2026-11-06，独立黑线结构待审。用户原话：“能不能水晶吊灯+slogan文字 然后再放拼贴 然后再到词条”。这取代助手上一轮默认研究“同画幅”的推进方向；不是用户选择了短前奏C或展开B。

## 交付

- sequence.svg：三段顺序对照，第二格仅示意拼贴首屏，并非只保留首屏。
- mobile-full.svg：390宽完整长图；开场760px，完整拼贴1260px，其后接正文占位。
- desktop-full.svg：1440宽；开场720px，原拼贴1320×1080以100%尺寸居中，之后接正文占位。
- index.html：查看入口；本目录运行python3 -m http.server 8779 --bind 127.0.0.1后访问http://127.0.0.1:8779/。
- checks.json：两端均包含一个slogan位置、完整10个原图像占位、一个图版组、一个正文组。

三段是同一条连续向下的阅读路径，无隐藏/展开操作。暂将用户“到词条”理解为接词条正文，不擅自增加路由跳转；如用户另有所指再调整。

## 与此前两种失败方案的区别

开场恢复足够的吊灯构图空间，以slogan负责情绪或观点。没有重复词条大标题、单独《秋千》或拼贴核心句。中段拼贴完整、直接呈现，原词条名/副题/10图/编号/核心句仍只在图版承担原有职责。正文随后解释，不是再次开场。

吊灯是既有02轮廓的简化黑线占位；不是新美术，也不能据此评价实际水晶细节。手机吊灯360px宽、x64/y12；桌面570宽、x850/y-80。构图尺寸只作本轮试排，不称用户已认可。

## Slogan尚未确定

已询问：全站共用一句，还是每词条各一句，或直接提供现成文字。当前保留“Slogan文字位置／内容与长度待确定”占位，不编造产品文案。

查阅既有Coquette快照，已存在副题“轻到一只鞋飞出去”、核心“Coquette 的迷人之处，是看起来柔软，却不意味着任人摆布。”二者均在定稿拼贴内，不自动搬到slogan位置，避免未经确认再次重复。没有读取或写入飞书新数据。
