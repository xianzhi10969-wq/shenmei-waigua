# 手机 P1 星星微闪候选 · 独立预览

用户提出把中间星星单独做一帧，实现闪烁。此目录仅作动效候选，未修改正式站文件、Figma或原图。

通过仓库根目录静态服务器打开 index.html。页面嵌入当前 P1–P3 发布副本，在手机开场显影结束后将原星形的墨线提取为 SVG 高光层；仍使用同一张原始无字 PNG，不重画、不缩放、不移动，不处理周围窗框、吊链或人物。

- 一个循环 5800ms，其中微闪约 812ms；高光由 0 → 0.45 → 0，其余时间停留原始帧。
- 原版静止 / 微闪候选 / 停在中间帧 / 重播开场可以对照。
- 下滑超过30px停止闪烁；返回顶部继续。减少动态效果时保持静止。
- Chrome 本地390宽预览检查：开场后候选启动；中间帧只改变星形墨线、无矩形底块；整页原位对齐。未做真机 Safari 测试，未获用户视觉验收。
- 线上仍为开场显影修复部署 `6ae6e9bbfc9fb75b68726055`，本轮未部署。
