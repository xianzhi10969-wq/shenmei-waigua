## F. 教训
1. 序号：P1、P2 都没有序号，P3 不应自带；要先跨页核对再加元素。
2. 「丑」的主因不是字体，而是层级太多、位置分散、间距无模数。先收层级再谈字体与颜色，顺序和 Skill 三阶段一致。
3. 不要把旧结论当事实：P2 实验稿是无衬线，不是衬线；颜色要实测，不凭「看起来像」。
4. 两色规则下，层级只能靠字号、位置、字重，线不能做灰；Figma 1x 下 0.5px 线会变灰。
5. 一次只推进一个阶段，每步新画板、旧稿不动。

### 8.2 细节处理
- **老式数字**：Cormorant Garamond 的「1889」是老式数字（样张里像「ı889」）。Figma 插件 API 不能开 OpenType 特性（lnum），所以改用同一设计家族的 Cormorant Infant，它的数字是 lining；只用于「1889」。已实测。
- **D 的数字**：样张里用 Marcellus 数字，手机 11px 下「1」像小写 l（「l889」），所以 v5-D 的 1889 改用仙人掌明体自带数字。
- **行尾悬挂**：沿用 v4：定义句最后的「。」和手机第一行行尾的「，」字距 -50%（居中后标点不撑开）。两套字体都有全角标点字形，位置为简体用法（偏左下），保持。
- **标点挤压**：出处里「》（」连续出现时，把「》」字距 -50%（Web）消掉相邻半个全角空；手机因为在「》」后断行，不需要。
- **手机断行与孤字**：版式没动，两行定义句 17+13 字、出处 15+15 字，无孤字，没有溢出。
- **层级**：页眉 12 + 加字距 → 定义句 24/14 → 出处 12/11。A 靠字重（Medium → Light → Regular）和斜体拉丁拉开；D 只有单字重，靠字号和页眉的 22% 小型大写字距拉开。
- **缺字**：按 topics.json（source + topics）全部 833 个非 ASCII 字符，用 fontTools 查 cmap：昭源 0 缺，仙人掌 0 缺。

### 8.3 自检（2x 图 Read）
不缺字，没有豆腐块，文字不溢出画板。差别：A 比 v4 笔画更细、反差更大，页眉拉丁是斜体；D 字形比 Noto 更古典，页眉拉丁变成小型大写，有碑铭感。整页缩略图下两套与 v4 差别仍小，需看 2x。

### 8.4 更正（2026-10-26）
此处原写「v4 手机上刻度条右箭头与出处末行轻微接触」。重新核对后**这是我自己把整页放大 2x 克隆（rescale）时产生的渲染伪影**：旋转 180° 的右箭头在缩放克隆里会偏移约 20px。在 1x 的真实画板上，左右箭头与刻度线同一水平，出处框 768–800，箭头在 813–827，**没有接触**。v5 报告里的该条建议作废。以后凡含旋转/翻转实例的区域，2x 放大不得用 rescale 克隆判断。
