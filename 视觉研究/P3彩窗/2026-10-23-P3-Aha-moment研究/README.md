# P3 彩窗｜Aha moment 研究（2026-10-23）

**状态：RESEARCH ONLY / 待夕里拍板 / 未实现**  
**边界：只谈 P3 自身的发现感。不重复 GPT 正在做的 P2→P3 接缝与窗框线质。**

---

## 0. 夕里澄清了什么

- P1 已经承担全站最大的「显影 / 落星」Aha。
- P3 不要再和接缝任务抢戏，也不要变成「目录墙」。
- 需要的是：**彩窗这一屏自己的发现感**——像走进展厅第一间房时那一下，而不是再演一遍开场大戏。
- 当前 v3（彩色封面 + 白石框 + 一格一格滑）夕里已说「好看」；问题是**好看 ≠ Aha**。

## 1. Aha 到底是什么（可复用的机制，不是「更酷」）

对照博物馆门槛、线上展厅与仓库已有对标，真正的发现感几乎都由同一组条件构成：

| 机制 | 含义 | 对 P3 的含义 |
|---|---|---|
| **沉默 / 停顿** | 揭示前先留空拍，让眼睛适应 | 到 P3 后不要立刻可滑；先有半秒「窗还没亮」 |
| **单一焦点变化** | 一次只变一件事 | 只亮中窗，或只推近一格；不要五格同时动 |
| **尺度切换** | 从「整面」感到「可进入的一格」 | 整扇圣窗 → 某一专题世界 |
| **光穿过玻璃** | 暗空间里颜色像被点亮，而不是贴图出现 | 夜玻璃先压暗，再让封面色「透出来」 |
| **整体再被拆开** | 先当成一件作品，后才变成可导航集合 | 24 专题先像一幅窗，滑是第二次动作 |
| **不与上一段抢戏** | P1 是大 Aha；P3 应是小而准的二次发现 | 禁止再做整页显影 / 再落一颗星 |

仓库产品共识里也写过：高价值来自「先感受再命名」「被说中」——P3 的 Aha 应是「原来这些感觉各有一扇窗」，不是「又看到一张漂亮图」。

## 2. 真实先例（全部可点开）

### A. 线上艺术站 / Readymag 系（仓库已对标，本轮复核）

1. **Emergence（Khoren Matevosyan）**  
   - 现场：https://emergenceprojects.com/ （仓库曾记 404，以访谈为准）  
   - 第三方截图：https://www.landing.love/sites/emergenceprojects/  
   - Readymag 采访（2026-08-26）：https://blog.readymag.com/interactive-websites-still-need-creative-judgment-designing-with-readymag/  
   - 移动端案例：https://blog.readymag.com/mobile-web-design-with-readymag/  
   - **Aha 机制：**不是炫技动画，而是「访客在场才激活」；Story 里树随滚动慢慢打开、种子出现、星在水面漂——**节奏跟读者走**。菜单像游戏入口，把站点变成可探索小展厅。  
   - **借什么：**发现感绑定「读者的动作」；动画为好奇心服务。  
   - **不借：**八角星、珠链、祭坛、具体角色（P1 复盘已禁止照搬）。

2. **People Look at Art…（Anton Repponen）**  
   - https://space.repponen.com/peoplelookatart/  
   - 作者自述：https://blog.readymag.com/personal-experiments-become-creative-work/  
   - **Aha 机制：**影子序列随滚动推进；缩放与阴影移动制造**逐步发现**，概念是「观看关系」本身。  
   - **借什么：**动作 = 概念（滚动像走近画）。  
   - **不借：**影子 PNG 序列本身。

3. **Hayal & Hakikat（Marina Meyer，同篇采访）**  
   - 采访同上 Readymag 文  
   - **Aha 机制：**滚动触发「相机闪光」揭开档案照——滚动从导航变成叙事手势。  
   - **借什么：**一个短促、可感知的「揭示手势」。  
   - **映射 P3：**中窗「点亮」可以类比闪光：短、唯一、有叙事。

4. **Readymag Design Stories**  
   - https://readymag.com/designstories/main/  
   - 幕后：https://medium.com/readymag/designing-stories-behind-the-scenes-of-readymags-editorial-series-9e00fc7d6ba0  
   - **借什么：**统一秩序下容纳不同画幅——对应「一扇窗、24 种封面气质」。

### B. Awwwards / 沉浸叙事

5. **Le Dernier Gaulois（Immersive Garden）**  
   - https://immersive-g.com/projects/le-dernier-gaulois/  
   - SOTM：https://www.awwwards.com/le-dernier-gaulois-by-immersive-garden-wins-sotm-for-january.html  
   - **Aha 机制：**六张手绘插画 + 连续滚动 + 波纹变形；教育内容被包进艺术推进，而不是目录。  
   - **借什么：**「一段故事推进」优于「一排入口」。  
   - **映射：**滑专题应像翻过下一扇叙事窗，不像刷卡片。

6. **Medieval stained glass（Ania Melnik）**  
   - https://www.awwwards.com/sites/medieval-stained-glass  
   - Scroll 元素：https://www.awwwards.com/inspiration/scroll-medieval-stained-glass  
   - **Aha 机制：**彩窗作为滚动叙事主体，色块与历史感一体出现。  
   - **借什么：**窗本身就是内容舞台。  
   - **注意：**他们可以全彩装饰；我们仍守双色框 + 封面原色例外。

7. **Real Estate: Stained Glass（Monks）**  
   - https://www.awwwards.com/sites/stained-glass-music-video  
   - **Aha 机制：**观众给动画彩窗上色，音乐同步——参与感制造归属。  
   - **借什么（弱）：**「我的动作改变了玻璃」；不必做上色游戏。  
   - **映射弱版：**悬停/轻触时中窗铅线微亮或夜玻璃变透。

8. **Glass video tiles assemble on scroll（The state of the gallery）**  
   - https://www.awwwards.com/inspiration/glass-video-tiles-assemble-on-scroll-the-state-of-the-gallery  
   - **Aha 机制：**碎块在滚动中聚成完整玻璃墙。  
   - **借什么：**先散/暗 → 后成完整一面。  
   - **映射：**进 P3 时五格可先「未点亮」，再聚成完整圣窗。

9. **Superlist 3D 书打开（仓库 S6 已引）**  
   - https://www.awwwards.com/superlist-by-gc-studio-wins-site-of-the-month-april-2021.html  
   - **借什么：**尺度切换——物件变大成为下一层界面。  
   - **映射：**点中窗 → 放大成专题/书页（属 P3→P4，可后做）。

### C. 博物馆 / 建筑（门槛与光）

10. **Chartres 彩窗：先暗后艳**  
    - 大教堂介绍：https://www.cathedrale-chartres.org/en/cathedrale/monument/the-stained-glass-windows/an-exceptional-ensemble-of-stained-glass-the-largest-collection-in-the-world/  
    - 历史观感（暗中殿衬托宝石色）：https://www.csmonitor.com/1993/0330/30161.html  
    - **Aha 机制：**走进近乎洞窟的暗空间，彩色玻璃像光源本身亮起——**颜色是被「透」出来的，不是贴上去的**。  
    - **映射最强：**P3 进场应有「暗 → 中窗透光」的一拍。

11. **Cleveland Museum of Art · Gallery One / Collection Wall**  
    - https://www.clevelandart.org/articles/gallery-one  
    - https://www.clevelandart.org/digital-innovations/artlens-origins/gallery-one  
    - **Aha 机制：**40 英尺收藏墙把整馆藏品收成**一面可触的整体**，再让人钻进单件。  
    - **借什么：**先「一整面收藏」，后「一件」。  
    - **映射：**五联窗先作为一件莫里斯式作品被看见，再允许一格一格挑专题。

12. **MFA Boston · Japanese Temple Room 数字门槛**  
    - https://ideum.com/portfolio/mfa-virtual-japanese-buddhist-temple-room  
    - **Aha 机制：**在真正静室之前设互动门槛，真厅保持肃静；数字探索与神圣空间分离。  
    - **借什么：**P3 本身可以是「门槛厅」——先感受窗，点进去才是内容厅（P4）。  
    - **映射：**不要在 P3 堆说明文字；说明留给下一层。

13. **Renwick「Global Cities」玻璃作品的 aha**  
    - https://insider.si.edu/2016/10/curiosity-exploration-key-deeper-aha-appreciation-global-cities-glasswork-renwick/  
    - **Aha 机制：**线索不全给；短暂的不解带来更深的「原来如此」。策展人明确说 aha 是让人回访的理由。  
    - **借什么：**中窗点亮前可以略延迟题名；先看见画，再读到「爱欲」。  
    - **忌：**谜题过难变成挫败。

14. **V&A 彩窗收藏与制作**  
    - 收藏：https://www.vam.ac.uk/collections/stained-glass  
    - How was it made：https://www.vam.ac.uk/articles/how-was-it-made-stained-glass/  
    - **借什么：**铅线组装、cartoon→裁片→上色→嵌铅——暗示「窗是被点亮的构件」，不是 UI 卡片网格。

15. **Lahti Historical Museum「Favourable Place」数字窗**  
    - https://pentagondesign.fi/casestudies/experience-concept-and-exhibition-design-of-the-main-exhibition-at-lahti-historical-museum/  
    - **Aha 机制：**真窗龛里嵌数字窗，望出去是另一时代；每间房一种气氛。  
    - **借什么：**「一格一世界」的空间隐喻（我们已有）；加强的是**气氛切换**而不只是换图。

16. **National Gallery · NG Stories**  
    - https://future-interactions.com/projects/ng-stories  
    - **借什么：**房间级叙事；数字展仍用「进一间房」组织，而不是无限瀑布流。

## 3. 对照：现在的 v3 缺哪一口 Aha

路径：`web-prototypes/p3-stained-glass-v3-2026-10-23/`

| 已有（夕里认可） | Aha 缺口 |
|---|---|
| 彩色封面 + 白石框 + 夜玻璃 + 卷轴 | 一进场就五格全亮，没有「透光」瞬间 |
| 24 专题一格一格吸附滑 | 滑动像浏览器，不像发现；侧格半露只是 UI 提示 |
| 玫瑰窗/星（结构意图） | 当前实现曾缺拱顶与星；即使补上，星也是装饰，不是「揭示开关」 |
| 中窗题名可读 | 题名与画面同时在，缺少「先感后名」的半拍 |
| 与 P1 同世界气质 | **没有属于 P3 的独立小高潮**；容易被理解成「又一张静帧」 |

一句话诊断：

> v3 已经是一扇好看的窗；它还不是一次「走进暗厅、看见光从玻璃里醒来」的事件。

这和 GPT 的接缝任务正交：接缝解决「怎么从水面走到窗下」；Aha 解决「站在窗下的那一秒发生什么」。

## 4. 三个只属于 P3 的方向（不含 P2 接缝）

### 方向 A｜中窗点亮（Dark nave → jewel light）——**推荐先做小实验**

- **一句话：**进入 P3 后短暂保持夜玻璃压暗（或封面几乎不可见）→ 停顿 → **只有中窗**被点亮透出飞书原色 → 题名晚半拍出现 → 之后才允许左右滑。
- **先例：**Chartres 暗中殿；Hayal 闪光；Glass tiles assemble；Renwick「先不解后 aha」。
- **映射：**星/玫瑰窗可作为「光源暗示」但不重演落星；24 专题仍在条带里，只是**第一次见面时焦点只有一格**。
- **为何不抢 P1：**P1 是整页世界显影；这里只是一格透光，时长建议 1.5–3 秒，可逆、可跳过（reduced-motion 直接终态）。
- **最小实验：**在现有 v3 上加一层「首次进入」状态机，不改封面系统、不改滑动数据。新目录另存。

### 方向 B｜整扇圣窗 → 可游集合（Collection Wall 再框）

- **一句话：**首屏把五联当成**一幅不可拆的莫里斯窗**（侧格不可滑、无箭头）→ 用户轻触中窗或星 → 铅线「松开」→ 才进入现在的一格一格模式。
- **先例：**Cleveland Collection Wall；Emergence 游戏式菜单；MFA 门槛厅 vs 真厅。
- **映射：**第一次 Aha =「原来整面是一件作品」；第二次才是「原来每一格是一个一级专题」。
- **风险：**多一步门槛，可能被嫌烦；需极轻（一次、可跳过、记住已见过）。

### 方向 C｜尺度推入（Pane → world）

- **一句话：**中窗 hover/tap 时，邻格压暗、中窗微放大、夜玻璃更深，像凑近一块玻璃；松手恢复；再点一次才进 P4。
- **先例：**Superlist 书打开；Real Estate 参与感弱版；产品方案 S6 窗格→书页。
- **映射：**Aha 是「这格是可进入的世界」，不是「换下一张封面」。
- **时机：**更适合作为方向 A 通过后的第二步，或直接服务 P3→P4；单独做也行，但不如 A 能先救「进场瞬间」。

## 5. 推荐给夕里（一拍即决）

**先做方向 A 的 3 秒小样，唯一变量：中窗点亮时序。**

验收一眼能判：

1. 进 P3 有没有「先暗后透」的半拍？  
2. 眼睛是否被钉在中窗，而不是在五格之间漂？  
3. 会不会觉得又在看 P1？（若会，缩短或去掉星动，只留透光。）  
4. 点亮结束后，一格一格滑是否仍然好用？

**明确不做（本轮）：**

- 不碰 P2→P3 接缝 / 拱顶线质（GPT 任务）  
- 不重做 P1 显影  
- 不做目录墙、不加说明长文  
- 不上色小游戏、不上 WebGL 炫技  

详细对照表见同目录 `对照笔记.md`。
