# P3 彩窗 · 中窗「爱欲」小样（方向 C 夜玻璃，2026-10-23，待夕里审）

**成品：`03_中窗爱欲_小样_final.png`**（900×2272，严格只有 #1E1E1E / #F6F3ED 两色，已用程序验证）。
构图速写：`01_构图速写.png`。提示词：`02_prompt_v1.txt`（第 1 轮）、`02_prompt_v2.txt`（第 2 轮，最终采用）。过程图在 `iterations/`。脚本：`tools/frame.py`（从线稿取窗框与玻璃区）、`tools/sketch.py`（速写）、`tools/composite.py`（反相、两色化、合成、卷轴题签）。

## 做法
1. 窗框：取夕里 459:2 线稿中窗（含尖瓣窗头、两侧柱、题签区），用 v2 清理版 `lineart-web.png`（去掉 “topic cover / title” 占位），放大 4 倍。石作保持纸白、原墨线；玻璃区填墨黑。
2. 题材：用图像生成画“墨线、象牙纸”的正稿（模型画正稿更稳），再**反相**：纸变黑玻璃，线变奶油线。提示词在 `STYLE_PROMPT_v7_EN` 的基础上改写，锁定：只出这一格、居中、中央 55% 宽、头部 30%、脚部 96%、玫瑰在 6–14%、两级线宽、不准有灰 / 排线 / 实黑块。
3. 两色化：阈值化后只剩两色；人物外轮廓用程序加粗约 5px（“铅线”），内部衣纹、花藤保持细线 → 三级线宽：石作窗棂（夕里原线 + 白石）最粗、人物轮廓中等、衣纹与藤蔓最细。
4. 题签：去掉原角框，改成燕尾卷轴带：「爱　欲」＋ EROS，奶油线。
5. 迭代：第 1 轮人物贴身、腿部轮廓清楚，像时装插画，不像伯恩-琼斯，玫瑰太小 → 第 2 轮：高领宽袍、垂直长褶、披纱，玫瑰放大并送进尖瓣窗头，藤蔓贴近人物、收窄 → 再修卷轴与题签区。共生成 2 次，合成 3 次。

## 自评（诚实）
- 好的：明度结构清楚（白石框 + 黑玻璃 + 奶油线），和 P2 的夜连续；玫瑰进入尖瓣窗头，有焦点也有向上的方向；对称、拉长，接近 Daniel 稿“一格一像”的感觉；藤蔓地稀疏，黑留得够。
- 不够的：
  - **衣纹太密太碎**：长袍里细褶很多，缩小后会糊成灰，违背“无灰面”的本意；伯恩-琼斯是少而长的褶。
  - **线宽层级不够明显**：轮廓加粗是程序沿外形描边做的，局部有不连贯、锯齿；不是真正的铅线绘法。
  - 藤蔓的玫瑰偏“贴纸式”重复，不如莫里斯的枝叶有生长逻辑；两侧几乎镜像，稍显机械。
  - 生成图分辨率有限：放大后线有轻微毛边；与 P1 的细线质感比略粗糙。
  - 卷轴是代码画的结构件（允许，属结构），造型偏简单，书法感不足；字体与 P1 标题字体是否一致需要再定。
  - 夕里原线稿本身只有 1448px，窗框放大 4 倍，石作线条偏软。
- 建议：如果方向成立，请夕里或插画师按这个构图手绘人物与衣纹（少褶、长线、真正的粗细铅线），藤蔓按莫里斯 *Briar Rose* / *Trellis* 的生长规律重画；我负责窗框、合成与动效。
