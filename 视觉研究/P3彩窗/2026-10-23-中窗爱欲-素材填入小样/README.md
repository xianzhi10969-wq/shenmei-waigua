## 做法
1. **构图**：原图 1280×1652 → 竖裁 `(380,60)–(820,1480)`，让人物落在格身、丘比特画进入尖瓣窗头方向；不是随机中心裁。
2. **转线稿**（自动，无手绘）：
   - 轻度 `bilateral` + `edgePreservingFilter`（去掉画布龟裂，保留大形）；
   - 颜色分割：黄裙 / 肤色 / 信纸 → 外轮廓加粗（当作“铅线”）；
   - `Canny` 细线只保留在人物邻域、窗框、暗色丘比特画区域内；
   - 局部过密处压成骨架，避免光学灰面；
   - **不用**排线块、灰度、渐变。
   - 试过：纯 Canny、XDoG、OpenCV `pencilSketch`、posterize 边界、LingDong linedraw（`-nh`；全流程 stroke-sort 过慢已中止）。最终采用「轮廓 + 分区 Canny」。
3. **合成**：夕里中窗石作留白 + 原墨线；玻璃纯黑；奶油色线稿；题签区改为卷轴「爱　欲 / EROS」。未加藤蔓地（画面已碎，再加只会更吵）。

## 诚实自评
**更像“加了滤镜的照片装进窗框”，不像莫里斯 / P1–P2 的线描。**

- 维米尔靠柔光与色块造型，几乎没有可提取的连续轮廓；自动算法只能抓住明暗跳变，线是断的、抖的、均匀线宽的。
- 没有真正的线宽层级（石作粗、衣纹细是框带来的，人物本身几乎一样细）。
- 丘比特画在暗部里几乎丢光，题眼弱。
- 与上一轮手绘小样比：手绘有完整轮廓与衣褶节奏；本轮只有碎边缘。
- 与 P1/P2 比：P1/P2 是设计过的少线、大留白；本轮是照片残边。

**结论**：这条“轻量路径”适合验证**构图与夜玻璃明度**（封面能否在尖格里站住），**不适合**当最终美术。若要用真实名画，仍需插画师按格重描（或接受“滤镜照片”的观感）。
