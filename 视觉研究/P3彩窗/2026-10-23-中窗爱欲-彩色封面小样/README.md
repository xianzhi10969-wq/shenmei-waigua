## 设计要点
1. **彩色是唯一例外**：封面保持飞书原色，未做单色/线稿。双色规则只作用于石作、夜玻璃、卷轴。
2. **不是贴纸**：画心用窗玻璃区域做蒙版（含尖瓣窗头小开口），并向内腐蚀约 12px（4× 线稿下），露出一圈墨黑，当作铅条槽 / 夜玻璃镶边，让画嵌进玻璃而不是贴在框上。
3. **构图**：竖裁 `(380,60)–(820,1480)`，人物落在格身，丘比特画朝向尖头；`cover` 铺满玻璃区并略上偏。
4. **卷轴**：题签区改为两色燕尾卷轴，奶油线 / 墨底。
5. **未做**：自动线稿、灰排线装饰、新插画。
