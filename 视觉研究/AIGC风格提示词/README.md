# AIGC 风格提示词｜让 P3 以后的插画和 P1、P2 是同一个世界

> 当前版本：**v7（世界观版）**，2026-10-21。直接复制用的文件是 [STYLE_PROMPT_v7_EN.txt](STYLE_PROMPT_v7_EN.txt)（推荐）和 [STYLE_PROMPT_v7_ZH.txt](STYLE_PROMPT_v7_ZH.txt)。
> `历史版本_已弃用/` 里的 v1–v6 只用来回溯，不要再拿去出图。

## 一、要解决的痛点

做 P3、P4 的时候卡住了两件事。第一，GPT 每次都在文字上保证“已经参考了 P1、P2 的风格”，可画出来的东西还是会跑偏：线条变粗、纸发黄、阴影变重、构图变成它自己习惯的样子。第二，GPT 能听懂“分图层”，但它的出图模型每次只会输出一张拍扁的完整图，没有办法真正分层。

第二件事的解法是分工：每一层单独生成素材，或者把已经认可的整图抠成几层，再到 Figma 里合成。这份提示词解决的是第一件事：风格一致。

## 二、它是怎么做出来的

做法是把出图模型当成“差生”来考：先自己拿提示词去生成，再把结果和 P1、P2 并排对比，哪里不像就改哪条规则，然后再考一遍。不先自己跑一遍就交给 GPT 的话，很可能一用就发现根本不像。

- **v1**：把 P1、P2 的特征写成具体规则。结果纸太黄、线条像铅笔素描、人物只是一个黑剪影。
- **v2**：加上精确纸色、“接近矢量的线条”和人物的画法。纸和线都对了，但空中到处飘小闪光，物件太简单，像图标。
- **v3**：规定细节程度和主体大小，星星只能长在东西上。门画得很好，可蜡烛被装饰堆成了“蛋糕”，场景变成了斜视角。
- **v4–v5**：加上平视视角、修长的轮廓、全图不许有灰色、地上的同心圆不许太大。这时候每张图都干净了，也很像 P1。
- **Aura 的纠正（这一步最关键）**：v1–v5 都在**规定具体元素**，比如必须是拉长的四角星、必须有柱子、方砖地、斗篷的格纹花边。Aura 指出，这只是在模仿表面形式。真正该统一的是一个**审美世界观**：这是一个什么样的世界，什么年代、什么材质、光和墨遵循什么规则、这里自然会有哪些东西。只要世界观对了，任何新元素放进来都会显得合理。
- **v6**：彻底改写成三段：给 GPT 的开头说明（用途、目标效果、哪些严格遵守、哪些自由发挥）、“这个世界”、“画法（严格）”。元素只当例子，不是必须项。用 P1、P2 里**没有出现过**的东西来考：写字柜、黑猫、楼梯平台加镜子、猫头鹰和鸟笼。结果没有一张图被硬塞星星和柱子，但每样东西都像是这个世界里的。新的问题是，世界观里列的地点和例子被当成了道具清单（黑猫旁边堆满了烛台、讲经台和楼梯），附参考图时纸色和鸟笼还带了棕色调。
- **v7**：加上“世界观是氛围，不是道具清单，只画要求的东西，最多一两件安静的陪衬”，以及“纸是中性的象牙白，绝不能是米黄或棕褐色；金属、玻璃、毛发、羽毛都只留白加轮廓”。复测时道具不再泛滥，棕色也没了。附了 P1 参考图的猫头鹰那张，模型还自己想到用一个黑色钥匙孔作为全图唯一的黑色重点，这正是“在世界观里自由选择”想要的效果。
- **v7 终稿**又补了两句（还没有复测）：黑色区域要保留白色的内部细线，不能变成平涂剪影；陪衬要和主体有关。

## 三、效果和还没解决的问题

- 最好的新元素对比图：[对比图/sheet_BEST_v7.jpg](对比图/sheet_BEST_v7.jpg)。上排是 P1、P2，下排是写字柜、镜子、楼梯加写字柜加少女、猫头鹰鸟笼（附 P1 参考图）、楼梯平台的镜子。每轮的完整对比图和文字记录在 `对比图/` 和 `轮次记录/`。
- 纸色、线条、留白：每张测试图都保持在象牙白纸和细线上，85–95% 是空白，比 P1 主视觉更空，和 P2 接近。
- **还没解决的：**
  1. **到现在都是用 Grok Bot 的出图模型测的，还没有在 GPT 上测过。** GPT 执行规则可能没这么严，先用 GPT 出 2–3 张，再拿回来对比修正。
  2. 中文版是英文版的忠实翻译，但没有单独拿去出图测过，英文版更稳。
  3. 附参考图时，纸色会被参考图带得偏暖一点，阴影也可能变重。
  4. 整体比 P1 主视觉更“轻”：墨量少、线条更均匀。P1 里人物斗篷那种密度，需要在“画什么”里专门写出来。
  5. 黑色主体偶尔会画成平涂海报剪影（v7 复测里的黑猫），终稿已经加了规则，但还没验证。
  6. 大约每 4 张会有 1 张小毛病（多一件没要求的东西、风格偏一个时代），重新生成一次就行。

## 四、怎么用

1. 打开 `STYLE_PROMPT_v7_EN.txt`，只改 “SUBJECT & LAYOUT” 下面方括号里的一行：写清楚画什么、放在哪，比如“一座写字柜，放在画面右半边，左边 40% 留空白给文字”。其他部分一字不改，整段粘贴给 GPT。
2. **一次只画一个主体。** 一件家具、一只动物、一个人物加一件陪衬，比一次画一整页稳得多。
3. 要附 P1、P2 参考图的话，在最前面加一句：“参考图只用来参考画法，不要照抄它的物件和构图。”
4. 出来的图有灰色、棕色，或者多了不相关的道具，就直接重新生成，或者补一句“去掉所有灰色，只保留轮廓线”。
5. 认可的图交给 Grok Bot，统一纸色和线条深浅，抠成图层，再放进 Figma 和 P1、P2 拼在一起。
