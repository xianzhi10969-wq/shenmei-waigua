## 三、已废提示词倾向与错误参考组合（简述）

下列组合／倾向 **本轮作废**，勿再当默认主跑：

1. **Style：P1 + King + *Documents Décoratifs* 大字／封面版心** — 冲淡 P1 干净线；大字版心尤忌。  
2. **提示词：建筑说明书堆砌**（肋拱、长凳、透视、花框条款过长）而几乎不锁「P1 级干净线 + 留白美感」— 易出「正确但无美感」。  
3. **文案内 `--ar 2:3`** — 在当前 Editor 路径无效，造成「以为竖图、实际方图」。  
4. **`--stylize` 偏高（约 80）+ 多 Style** — 糊线、海报感加重。  
5. **坏花框上本地 Erase** — 毁框。  
6. **把 Aha 中窗点亮／junction 提案当已验收或可升基线** — 明确否决或仍待审。

仍可参考、但须按新约束重跑的资产：

- 「好看」中殿构图裁切 → 仅作 **Image Prompt 构图**，不作 Style。  
- GPT 中殿结构草图（`web-prototypes/p4-nave-structure-v1-2026-10-23/` 等）→ 只借空间结构，不借装饰发明。  
- P1 认可线描 → **唯一 Style 锚**。

## 四、下轮正确约束（生成前核对清单）

1. **Style：只留 P1**（一张）；拿掉 King／穆夏标题版心／其它气质板。  
2. **Image Prompt**：需要时只用「好看」中殿构图（已压小）；传不上就跳过构图，先靠 P1 Style + 提示词。  
3. **比例：UI 先设 2:3**（或 9:16）；**提示词里不写 `--ar`**。设好再点生成。  
4. **参数**：`--stylize` 偏低（约 **25** 起步）；有参考时 `--iw` 可约 2；其余默认。  
5. **提示词优先级**：先写「匹配 P1 干净自信黑线、象牙白纸、近矢量、有呼吸留白、有美感与秩序」；建筑中殿作辅，禁止零件清单压过线感。  
6. **两色铁律**：`#F6F3ED` + `#1E1E1E`；无灰排、金、颗粒、渐变、阴影、签名文字。  
7. **分工**：细画 → MJ（本清单）；结构／接缝／滚动／交互动效 → GPT；装饰细画不交给 GPT 从零发明。  
8. **工程**：新窗与层只增量、另存目录；**不覆盖** v4／v9／彩窗 v3。  
9. **验收语言**：出图／提案一律标 **未验收／不升基线**，直到夕里明确说通过。

--stylize 25 --iw 2
