- V5 跨界造成粉色面积缩小 → 已否定并回到 V4 色块比例。

- 任何仅重排 PPT、增加 CSS 曲线、添加图框、给四条临时文案强配插图的「艺术深化」均不构成下一轮可继承成果。

## 4. 交接原则 / 下一轮唯一入口

1. **先打开上述 Figma 回滚画板（281:2）与 Library 原版 V7 HTML**，确认不是 V9/V10 或更早的 A5。
2. 不再默认增添装饰或换版式；先提出一条关于**文字、图片、色面、图形、界面状态之间关系**的可验证创作命题，在浏览器里实现真正的视觉材料实验。
3. 每一件素材都要有明确页面功能；**逐件生成、逐件落位，整轮集中验收**。不把一张包含多个元素的图片当成可编辑看板。
4. 先内部比较、淘汰失败试验；给用户看的必须有前后真实渲染，且说明变化在哪里、为什么有效。
5. 未经新的审美确认不修改已认可视觉基线，不将本轮归档称为网站已上线或用户已验收。
6. 用真实浏览器检查字体是否加载、视觉层是否越界、桌面和手机的截图与交互；静态检查通过不代表视觉验收。
