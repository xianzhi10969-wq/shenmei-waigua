# P4 衔接与星星双路径研究

2026-10-26｜结构提案，待审。依据远程 master `3e4677c984c61f1cac68f52add5fbaa03a58ff35`。不修改 P1–P3、旧 P4、Figma 或飞书；不生成正式美术，不实现生产导航。

## 结论

同一美术世界，可以有两种行走速度。首页允许慢慢探索；星星提供随时可用的总索引。目标明确的人不必走完首页，但到达的是同一个专题/词条页面，不另做一套普通后台式界面。

P4 推荐作为“彩窗下展开的专题图谱”：空间从看窗转成看作品的关系。原有纸墨、钢笔线质、少线和大留白延续；不指定柜子、书册、长凳、中殿为新场景。图谱是内容组织概念，不代表拟物翻书。

## 先分清三个层级

- 星星：全站五功能索引。寻找感觉、美学专题、好奇心漫游、意象实验室、艺术资源。不是24个章节，也不是首页屏号。
- 24格：章节位置与切换。P3与P4共享当前章节，绝不把24格重新解释成当前章节的词条进度。
- P4：当前章节的细分风格浏览，可进入 V3 词条。章节长文从独立“读本章”进入，避免P4同时承担完整章节、全部词条正文和导航。

## 星星怎么既有叙事，又随时可用

以下为本轮建议，尚未验收：

1. 首屏就给星星配一个简短“总索引”文字入口，不让用户猜图案含义；无需先选择探索模式/效率模式。
2. 场景星处于可见静止位置时，图与文字共同可点。运动离开视野或被遮挡时，由页边停驻位承接同一个索引入口；只有一个可交互/可聚焦实例。具体停驻侧边未定，不擅自指定右侧。
3. 点击立即响应并冻结背景滚动/星星运动。轻量揭幕，不必等落星或长转场完成。减少动态偏好时直接打开；按Esc/关闭回原位。手机触区至少44×44，正文名可见，键盘可聚焦。
4. 保留已确认 Le Pater 布局：左1/5五枚等大等权徽章，右4/5真实功能页预览，标题带叠压。徽章配功能名，不能只凭抽象图案认路。换徽章只换预览，不误跳转；明确“进入”后才导航。
5. “美学专题”的真实页面提供“彩窗浏览 / 章节目录”两种观看方式。目录允许一次看到24个章名，按真实顺序列出；此处是内容目录，不是把全站索引改为24宫格。选择章名可直达同一章P4，省去逐格翻页。仍保留“读本章”去章节详情。
6. “寻找感觉”仍是独立功能；可以同时识别已知章节/词条名和感觉词的检索意图（待单独数据设计）。不在P2四问里插搜索框，不把“随便逛逛”变成强制流程。

操作例：已知要看“田园” → 星星/总索引 → 美学专题 → 在该真实页面目录选田园 → P4田园图谱。仅想进意象实验室 → 星星 → 意象实验室预览 → 进入。未实现的目的地标明未开放，不给假跳转。

直达与探索必须共用 topicId/entryId 和内容路由。打开索引保存来源页、滚动位置、当前章节及细分条目；关索引原位恢复，进入目的地后返回也恢复。直接链接进入P4不播放P1至P3整段动画。当前默认功能可由所在页面决定，但五枚入口保持等权；不擅自指定永久默认“寻找感觉”。

## P3 → P4：推荐分镜 A

**命题：刚才隔着窗看的一种感觉，现在展开成可以辨认、比较和继续阅读的内容。**

1. P3稳定态：当前封面、章名和24格是三个锚点。用户横滑停稳后再往下走；点章节题签去章节详情的既有产品关系保留，不偷偷改成另一种点击结果。
2. 下滚跨页：原窗框整体随滚动上移，不能把石框揉成矩形。当前封面在独立过渡层接续，先保持同一裁切/屏幕位置，再逐渐显露原画更多范围；封面不重绘、不拉伸。章名留在读者视线内，24格保留章节语义。这里不再让星星表演一次大幅飞行，它转为可用的索引入口。
3. P4落定：桌面同一画面里，一幅主作品与细分风格目录相互对应；章名、短定义、读本章入口为辅助。选细分风格后才换主预览，点“阅读词条”进入V3。初始主图仍用章节封面，避免一落地就自动变成第一个细分词条。
4. 返回：反向滚动恢复同一章节与原裁切；回到P3不得重置第一章。索引打开时中止滚动转场，关闭后恢复。

**Web草排**：1440×900。左右64px，内容宽1312；主画区域752px＋间距32px＋目录528px。图像按原比例容纳，不以裁脸/拉伸填满。24格沿用已有桌面规格；此处位置仅草排。

**Mobile草排**：390×844。左右24px，内容宽342；从上到下为章节身份与换章入口、24格、主画（约220px高）、词条列表首项。首屏要露出可点的细分项，不能被一幅大图和一整段开场动画占满。列表纵向阅读，不再嵌套一条横滑词条轮播；横向手势专用于章节切换。

图谱条目用真实章节关联与顺序；草图仅写“细分词条”占位，不编造某章的分类数量。图片不足时用真实名称和短定义呈现，不制造假插图。

## 对比方向

| 方向 | 衔接方式 | 优点 | 风险/判断 |
| --- | --- | --- | --- |
| A 窗下展开图谱（推荐） | 封面、章名保留，石框离场，内容关系展开 | 保留来源，也能让读者较快开始选择 | 要实测画心由裁切到完整图的连续性；不能变成普通图文PPT |
| B 沿窗下移、目录接在窗座之后 | 没有额外缩放，只做同轴纵向接续 | 动作最少、返回自然，手机代价低 | P3插图若过长，内容仍来得太迟；可作简化动效回退 |
| C 穿入封面、再出现词条 | 镜头推进作品世界 | 沉浸感可能更强 | 易放大模糊、裁掉原画主体，后续又要退出画面；目标型用户等待成本高，本轮不推荐 |

## 配色研究结论（不是色板定稿）

纸面和墨线是固定环境，艺术作品保留原色。先保持P3→P4纸底连续，靠作品尺度与黑白密度变化产生新一页，而不是每页再反相一次。只有确实改善作品轮廓辨认时才研究局部深色展底；不给每章自动染一种背景，更不把“田园=绿色”当分类真理。

星星打开索引时，揭幕/遮盖应延续纸墨关系，右侧是实际功能页面。不要另画五幅主题插画，也不沿用旧灰块/圆章/黑条为正式美术。

## 收束与下一步验收

先审两件事：A的“窗下图谱”空间关系，以及“随时可点总索引”的可发现性。通过后先做共享状态和可逆的黑白交互分镜；再单独定停驻位、索引揭幕、P4艺术素材与色彩/字体。五枚徽章仍逐枚研究验收。

验收任务：新访客能认出星星可打开总索引；已知章名无需滑24次；关索引不丢位置；直达P4和滚动到P4看到同一章；手机先看到能选的条目；返回后24格和封面一致。以上为验收目标，尚未进行用户测试。
