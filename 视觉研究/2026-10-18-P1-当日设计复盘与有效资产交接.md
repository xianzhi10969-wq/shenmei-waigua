## 1. 一天的设计演变：不再重复的关键结论

从 V7/V8 字图纸面底印、OSP 和 Emergence 的艺术方法研究，发展到独立黑白线描首屏、独立人物 / 中心圣匣 / 背景层、三种桌面展示方式和手机独立构图。**重要变化不是「多加素材」，而是先构思再分层画图，最后才作网页排版。**

用户反复指出的失败：
- 80 分的「好看」不能靠更换边框、调字体大小或叠一层纹理冲到 90 分；艺术首页应先建立一个可以记住的整体视觉世界，而不是 PPT 式版面。
- 学习 Emergence 的结构、线描密度变化与展陈方法，**不能直接复制其星体、几何柱饰、器皿、漂浮图案**。曾发现借鉴过度并明确要求替换。
- 仅靠 CSS/SVG 程序几何生成的人物线条僵硬；素描式灰阶、均质排线也偏离 Beardsley / Harry Clarke 风格。应制作绘画素材，代码只在网站落地阶段服务它。
- **所有图层同样复杂不成立**：背景单调、重复、低密度；建筑中密度；主体物集中；单侧人物深袍拥有最丰富的黑白明暗和有取舍的衣褶。
- 首屏不放四个问题；标题 + 主视觉第一眼立世界。四问题不是被删除，而是保留为下一屏及以后交互内容。
- 手机端必须独立 Art Direction，不能把桌面图片缩小塞在下半屏。
- **每次新排版必须继承已经认可的字体资产**；不得从系统默认宋体重新开始，也不得误把 SVG/CSS 线条演示当成绘画成品。
- 用户明确要求：是否暂停、何时结束由用户决定；不得在未授权的情况下自行说「今天就到这里」，也不应消耗整轮对话道歉而不推进。

## 4. 今天学到的制作方法

1. **先构思构图**：横版安全区、手机竖屏安全区、人物与中心物的关系必须先定；后上标题，不是先做网站。
2. **分工序产生图层**：背景重复而单调、神龛线描稳定、仪式器物轮廓鲜明、人物笔触深且富变化；素材单独生成/裁切、独立验收，再组合，禁止一次性全画完。
3. **原创性优先**：借 OSP / Emergence / Hermes 的媒介思维、展陈与层级，而不借现成物种或图案；相似的祭坛器皿必须替换。
4. **锁定是工程规则**：通过的图像、字形、交互经验都列明其文件和出处。之后的每轮迭代只动声明范围；本轮字体默认回退是缺少资产锁定的直接教训。
5. **实际视口比描述重要**：手机独立安排标题 + 放大人物 / 圣匣，才能追求“一屏的震撼”；要在真实 375、390、430 的浏览器渲染中检查。
6. **有筛选的实验**：四轮纸纹/墨点/网点尝试没有明显审美增益，应淘汰；不会因为 GitHub 找到工具就把每种效果硬加进成品。
