# 排版工作室 v1

为「审美外挂」准备的独立布局工具。可在视觉参考、插画尚未定稿时使用空白画布、可编辑文字和占位块工作。工具界面不代表最终网站视觉方向。

## 打开

在 Finder 中双击 **启动编辑器.command**，浏览器将打开 <http://127.0.0.1:8765/>。保留启动时出现的终端窗口；关闭窗口会停止服务，已保存内容不会丢失。如果系统阻止双击，可在终端运行：

```sh
cd '/Users/yuriko/Documents/ChatGPT/审美外挂 2/tools/layout-editor-v1'
python3 server.py --port 8765
```

然后用 Chrome 打开上面的本机地址。只依赖 Python 3.9 或更新版本，没有安装依赖、云端账户或上传步骤。

## 第一次使用

1. 左侧新建或重命名场景，对应分镜中的一个画面。
2. 选择「桌面」或「手机」。这两端分别保存，切换不会重排另一端。
3. 没有素材时，添加占位块和文字，安排主要区域。画布尺寸在未选中图层时的右栏设置。
4. 素材确定后，导入原图，点击素材卡片放入当前画布。每次放入都是一个独立实例，原图不会被修改。
5. 拖动物件；拖右下角调整尺寸。右栏可以精确修改位置、宽高、旋转角度和透明度。图片默认保持比例。
6. 在右侧图层列表中调整前后顺序、隐藏或锁定。最上面的图层显示在最前。
7. 等顶部显示「已保存到本机」，点击「预览」。预览与编辑器使用同一份布局数据、同一个渲染函数。
8. 点击「导出项目」保存包含原图的 JSON 备份。导入项目时追加场景，保留现有场景；可以撤销此次导入。

手机布局可以从桌面按宽度等比复制作为起点，但需要手动调整；复制会先提示，并且可以撤销。每端画布可以设置更长的高度，预览时正常向下滚动。

## 已实现

- 多场景：新建、命名、复制、删除（至少保留一个）。
- PNG、JPEG、WebP、GIF 素材库；拖入文件或点击导入，单张最大 12 MB。素材库共用，删除画布图层不会删除原图。
- 图像、文字、中性占位块；拖拽、右下角缩放、属性栏旋转、透明度、图层顺序、隐藏与锁定。
- 独立桌面／手机布局、画布尺寸和底色、缩放和适合窗口。
- 撤销／重做，当前窗口最近 60 个编辑状态；一次拖动只记录一次。
- 修改后约半秒自动保存。磁盘采用原子替换，保留最近 20 份已保存状态备份。
- 同一台电脑、同一本地服务的窗口约每 2 秒同步。存在未保存修改时，旧窗口不能覆盖新版，会显示冲突提示；可先导出本窗口，再读取最新版本。
- 项目 JSON 导出内嵌原图；导入最大 64 MB，保留现有项目并重新分配 ID。
- 预览自动读取最新已保存版本，文字仍是文字，原图仍是原图。

快捷键：⌘/Ctrl Z 撤销；⇧⌘/Ctrl Z 重做；⌘/Ctrl D 复制图层；方向键移动 1 像素，Shift＋方向键移动 10 像素；Delete 删除；Esc 取消选择。输入文字时这些图层快捷键不会抢占输入操作。

## 保存在哪里

运行后自动生成：

```text
data/project.json       当前项目及版本号
data/assets/            导入的原始图片
data/backups/           最近 20 份旧项目状态（图片由 assets 共用）
```

需要完整迁移时，复制整个 `data` 目录或使用「导出项目」。备份 JSON 单独不包含图片。不要在编辑器运行中手动改这些文件。重启服务后恢复最新保存状态；撤销历史只保留在当前窗口。

多个 Chrome Profile 也可访问同一服务并共享数据，不需要共享浏览器登录。它不是多人云协作工具。

## 当前边界与验证

- 这是素材排版器与静态布局预览，不包含跨屏叙事动画、滚动时间轴、真实业务数据连接或网站发布。
- 没有多选、分组、对象对齐参考线、图片裁切、自由路径或自定义字体上传。字体暂为系统无衬线／衬线／等宽三类。
- SVG 暂不接收；请先导出为 PNG。最终网站的响应式逻辑、素材加载策略和交互，后续在方向确定后单独制作。
- 编辑时允许看见画布外的物件，预览裁切到画布边界；文字高度过小时仍可溢出文字框，排版时应留足高度。
- 7 项后端自动检查已通过：保存／重启恢复、桌面手机分离、过期版本冲突、素材原图保留、上传原字节读取、非法参数及访问边界。
- 前端脚本通过语法检查；隔离的数据逻辑检查覆盖两端隔离、撤销／重做、原图保留、锁定删除保护、复制 ID、导入校验和旧轮询响应保护。此轮浏览器控制连接连续超时，尚未完成实际拖拽、文件选择、下载和跨窗口 UI 验收；不能把这些视为已通过人工操作验证。

运行后端检查：

```sh
python3 -m unittest discover -s tools/layout-editor-v1 -p 'test_*.py' -v
```

若本机安装了 Node.js，可另外运行 `node tools/layout-editor-v1/test_frontend.mjs` 检查前端数据逻辑。Node.js 不是使用编辑器的依赖。

工具全部独立保存在此目录，未修改现有网页原型、视觉素材、Figma、飞书数据库或部署。

## 2026-11-12：从素材排版直接接到网页

1. 左下点击「网页连接与检查」。可以查看八个已接入位置，分别检查手机、桌面的可见图层；缺图、重复连接、旋转后超出画布会提示。图层数量只代表排版状态，不代表美术通过验收。
2. 点「补齐空白场景」，仅追加缺失位置的空画布；原场景、原图保留，重复点击不会再建一套，也可以撤销。1200×800／390×600 是可改的排版起点，不是艺术规格。
3. 点画布空白处，在右栏「放到网页的哪个位置」用中文选择用途。已被别的场景使用的位置会禁用；需要换场景时，先在原场景选择「暂不连接网页」。复制场景会自动解除副本连接，防止两个场景争用同一个位置而无法保存。
4. 选中图片后，可在右栏「替换这一层的图片」选择素材库里的另一张图。只换当前实例，不修改原图或其他实例；普通模式保留框的位置和大小，像素模式保留位置并取新图的最近整数倍尺寸。被锁定的图层不能替换。
5. 完成保存后，可点「保存并看网页」。需同时运行游乐园本机服务 `http://127.0.0.1:8871/`；共用专题牌楼先进入浏览区，再点任一专题查看。
6. 点击左下「下载网页包」，编辑器先保存当前修改，再生成 ZIP。只带网页已连接场景及使用的原图、功能代码和内容快照；没有连接的草稿、项目备份、浏览器票根不包含。完整可编辑项目仍用顶部「导出项目」。

ZIP 保留在 `data/exports/`，方便下载中断后找回；不会自动删除旧包。解压后按包内使用说明打开（需要 Python 3 或普通静态网站托管）。导出版本与后续编辑独立，也不会自动发布。若另一窗口已保存新版，会拒绝按过期版本打包；应先同步再下载。

连接位置定义集中在 `site-slots.json`，编辑器下拉框、检查列表和网页打包范围共用它。原有自定义位置保留，但尚未接入网页的位置会明确提示，不能误认为已经生效。
