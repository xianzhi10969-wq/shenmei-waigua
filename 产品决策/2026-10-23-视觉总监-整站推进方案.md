1. **现在真正“定了”的只有三样**：P1→P2 显影＋星 B 落水 v4；P3/P4 v9 柜体→书册（受保护）；星星导航的 Le Pater **布局**。其余（彩窗 P3、徽章美术、标题带、字体、P2→P3 衔接）都还是待审。

## 2. 诊断：为什么 P1→P2 之后卡住

1. **结构未锁就出图**：P1 复盘自己写了优先级应是“构图与世界观 → 单件绘画 → 组合 → 网页交互”，过去多次倒过来（`视觉研究/2026-10-21-P1黑白线描主视觉-从失败到候选图的全流程复盘.md` §一）。P3 的 v10 被否（“喧宾夺主”）也是同一问题。
2. **一轮同时改多个变量**：AGENTS.md 已要求“标记本轮变量”，但实际每次 GPT 出图都同时改构图、线重、纸色、内容。
3. **出图模型不能分层、不能精确复现**：v7 README 自述 GPT 只输出拍扁整图、风格跑偏（`视觉研究/AIGC风格提示词/README.md` §一）。
4. **验收标准是“感觉”而非可比对清单**：缺“和 P1/P2 并排自测”的固定检查项。

### 新的生产方法（每条都有出处）
- **分镜 → 动态分镜 → 成品**：先用分镜锁构图，再用 animatic 锁时间，最后才做昂贵画面（Boords animatic 指南；M Studio previs/storyboard/animatic 对比）。
- **一次只放开一个变量**：每个交付物标注“本轮唯一变量”，其余锁定（AGENTS.md「结构草图优先」）。
- **结构与几何骨架用 SVG，正式美术不用 SVG 冒充**（见失败账本 F5）：窗框、尖拱、玫瑰窗、徽章外轮廓、星都是几何构成，Gothic 窗花本来就是圆规作图（Archistory 哥特窗几何），星 B 已是 SVG（v4 `star-svg/`）。SVG 可描线动画、可逆、轻（motion.dev、css-animation.com）。人物、花叶、装饰等正式美术按单件制作（可生图），只出**单件**、按 v7 提示词，并与 P1/P2 并排自测。
- **自测清单（每件交付前必过）**：只用 #F6F3ED/#1E1E1E；外轮廓粗、内线细两级线重；黑色面积不超过 P1 同尺度的量（待核验具体比例）；有轴线和秩序；与 P1/P2 并排截图一张。

- 风险：v9 的 P3→P4“柜门放下变书桌”机械叙事会丢失 → 需要新的 P3→P4（见 S6）。

### S12｜字体
- 不一致：仓库里同时有 Yozai Light（P2，Figma 323:*）、cabinet-song、folio-song-v1、folio-title-engraved、folio-title-fractured、folio-latin-fraktur（v9 assets）——太多。
- 建议：收敛为“一中文宋体正文 + 一中文标题刻字 + 一拉丁衬线”。中文网页字体需子集化（pyftsubset，Noto Serif SC/思源宋体 7 字重，google/fonts METADATA；eigenigma 自托管 CJK 实践）。
- 待核验：各字体授权（v9 assets/licenses）。

### S13｜手机 vs 桌面
- 原则：手机是重新取景，不是缩小（P1 复盘 §一；web.dev art direction）。触控目标至少 44×44（W3C 2.5.8 / BBC 指南），手机不依赖 hover。
- 彩窗手机：中间整格 + 两侧半格提示可横滑（441:44）。

### S14｜hover / tap / 回滚
- 桌面 hover 只预览不跳转；手机 tap=选中、再 tap“进入”=跳转（交接 §3 交互状态）。所有滚动动效 scrub 可逆（GSAP），用 `@supports (animation-timeline)` + reduced-motion 双门控做渐进增强（css-scroll-driven.com；MDN view()——Limited availability，需 JS 回退）。
