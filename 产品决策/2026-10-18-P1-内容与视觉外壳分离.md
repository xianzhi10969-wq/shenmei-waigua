# 【CURRENT / AUTHORITATIVE】P1 的视觉外壳必须与示例内容解耦

> 更新 2026-10-18。用户审阅 Codex A5 截图后的明确产品纠偏。
> **状态：当前有效设计约束；A5 仅为试件，未通过设计系统验收，未上线。**
> 已有资料会反复提到“四句具体问题”、`04 旧物`、`宋冬`《物尽其用》等。这些内容**均是用来测试用户困惑与 hover 效果的演示数据，绝不是 P1 的永久文案或固定主视觉设计依据**。

## 用户真正要 Codex 做什么

用户一直在要求**网站本身（front-end shell / visual identity / editorial design system）的艺术性**，而不是为当前四句演示文案完成一张精美海报。

- P1 首页美术系统应具有清晰、独立、精致的视觉身份。即使换掉四句困惑、换掉当前默认艺术作品，画面的组织规律和品牌感仍然成立。
- 视觉不等于无差别模板：设计应给内容规定有效的角色、尺度与关系，让它能优雅容纳不同的文字长度、艺术作品比例、媒介差异及缺失字段；不强制把内容改造为某一个例子的形状。
- 用户肯定的机制是 A3 的「hover 某一种心声，作品即时切换」，**应保留**。机制并不意味着目前 01–04 的文字、排序、数量或配图已经被批准。
- A、G17 目前真正认可的品牌语法是：黑底白色植物雕花边框、暖纸色、像素字标、少量暗红、四声部有呼吸的阅读感。它们是设计依据，不是必须复刻原像素的死板页面。
- 先做真正可扩展的视觉外壳（page shell），而不是用`04 旧物`素材来构成整页主体；不要在 CSS/HTML 中写死“旧物”“旧物留住的也是用过它的人”等内容。
- 原有四句可以保留为一套**test fixture / 测试数据**；它们的语义、句长、数量和对应作品都可能被策展替换，不能成为「组件视觉完成」的必要条件。

## A5 失败的准确界定

- 这次 A5 实现了一个相对平整的文字问题列表和一张很大的《物尽其用》图片，默认第 04 句被酒红强调。**不等于用户确认了该作品应出现在首页**。
- 若将 04 换为没有旧物主题的心声，或将图像换为竖幅/极简摄影/抽象装置，A5 是否仍然有成熟视觉构图尚未验证。
- 因而它虽然可能是“某一张示例排版”，还**不是用户真正要的、可复用的美丽网站外壳**。
- 不得继续只围绕现成示例内容修标题、配作品、写赏析，或者用永久硬编码来“优化艺术感”。

## 三层必须真正分离

1. **稳定品牌外壳 / Visual system**：框架、内页版面、字体尺度规则、留白/密度节奏、版心、纸色、点击/焦点/切换视觉语法与响应式规则。
2. **可替换内容 / Data**：心声的具体句子、顺序、预览作品的图像/署名/说明、未来揭示的美学术语/关联逻辑；全部以独立数据配置驱动。
3. **交互状态 / Behavior**：hover/focus/tap 导致当前声部变化、画面即时响应、作品查看与返回；不要把交互逻辑和具体的 `04` 或某张作品绑定。

## 接下来怎么验证“外壳真成立”

先不开发另一张单一示例海报。请提供**一个统一的视觉系统，在三套测试内容下渲染**（无需用户亲自操作）：

- **Set A：当前四种审美困惑**（仅作为对照，不当固定产品文案；含横幅/彩色/多元素作品）。
- **Set B：另一组语义和长短完全不同的四句**（需标记测试假数据；作品可能是竖幅、留白多、黑白/低饱和，不借用未经授权的他人艺术作品，可用可审查占位构图验证）。
- **Set C：短句、长句混合 + 极简抽象物件或不同长宽比 + 至少一项缺少补充说明**，用以检验布局韧性和变长行为。

**这三张图必须是同一份组件、同一套 CSS/设计 token，切换数据即可得到，不允许为不同数据集单独改版。** 3 张默认状态 + 至少一种 hover 切换视图；桌面优先，手机结构稍后单独设计。当前演示数据可以用自己的临时内容，但不得伪装正式艺术家案例或乱编署名。

验收不是“所有内容都能塞进去”，而是：
- 无论是哪组素材/语句，**网页仍然像一个有艺术指导的完整作品**，没有瞬间跌回 PPT；
- 视觉主次来自系统，而不是始终依赖那幅`04`大图；
- 作品比例不同也不随意粗暴裁切，不以内容覆盖品牌边框；
- 更换测试数据不需要开发者去修改构图代码；
- 既有 A3 交互逻辑被保留（后续接入），而非被重新发明。
