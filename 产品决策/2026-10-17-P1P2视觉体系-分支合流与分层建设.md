## 01 合流后的真实问题

用户认可 P1「普通人的审美困惑」和 P2「香水柜里认出熟悉的美，再认识其名称」的体验骨架。但已制作的 P1 多声部、P1 拼贴三案，虽内容结构相对正确，**在艺术元素设计、图文关系与资产质量上依然平铺直叙**。

用户特别喜欢 [Alex Valcarcel 网站](https://readymag.website/u3360856796/4541073/)／其截图里的**人体简化线描／图解式人物**：精简的外轮廓、人物姿态、垂直分割线、箭头、几何作图线、跨版面覆盖，不是大量写实画面堆积。此偏好不是要求照搬页面，也不表示用户想在每只瓶子贴一张人脸。

用户提出更好的制作顺序，应像建筑工程一样：**地基 → 结构 → 视觉语法／空间 → 专用素材 → 页面组装 → 代码与验收**。前端不能靠临时用 CSS 拼凑全部视觉效果；应先为网页制作和验收可复用的原创视觉资产，再由 CSS、SVG、图片和 HTML 各司其职。

**重要技术澄清**：不是 CSS 无法做高级设计，也不是“所有东西都要生图”。CSS 管尺寸、排布、响应式、状态；SVG 管清晰可伸缩的线描与装饰；PNG/WebP 管复杂透明插画；HTML 管可检索可编辑的正文和语义。素材要在浏览器里验证，避免“单张效果图好看，真正上线变形”。

## 04 合流的内容骨架

P1 —— **让用户知道自己的审美直觉受到重视**。多种普通人的真实困惑在画面中相互回应：有感觉但讲不清、认得出美但不知道名称、想知道美在哪里、想找到类似的。不能把「不会搜索关键词」扩大成唯一核心痛点。对话感可以来自排版/声音/批注，不必是圆角聊天气泡。

P2 —— **香水柜的行动与发现**。第一眼可推断“这些瓶子代表不同的美”；凭眼缘选瓶 → 试闻/感受 → 打开瓶签看到一种可继续了解的美学名称。名称提供可能的解释，不把个人感受判为唯一正确答案。

P3/索引/搜索如何接续仍待探索。**不再默认旧 P2、P3 原位不变，也不把 P1/P2 当前顺序说成已完成最终验收**。

## 05 视觉语法第一版，供 Figma 板实测

### 线与造型
- 目标：**示意图式人物**，优先身体轮廓与动作、少量内轮廓（不是具象肖像、不会出现每瓶同一张脸）。
- 一致性：同一视角/线条家族的外轮廓，允许不同风格瓶子在瓶盖、瓶身结构、姿态、重心上产生显著变化。
- 图解线：连接线、延长线、圆弧、参考刻度/轨迹从“发现/感受”的信息关系里长出来，拒绝为了装饰随机添加。
- 页面复杂度：只设一个强视觉焦点；精细外框与瓶形/人物线描不应争夺同一级注意力。

### 文字与对话
- 保留“像懂审美困惑的朋友”的口吻：读者语句可短而直白；副注用较小字号、编排式注释。
- 标题与正文要保留真正 HTML 文本可访问，不要把全部文字烘焙为图片。
- 对话是多声部表达，不是假装聊天机器人；若视觉上可点击，必须存在对应功能，不能让读者误会能获得对话回复。

### 色、肌理、交互
- 先用黑／纸白／单一强调色检验形体和构图，再试有限上色，避免用渐变解决造型不成立的问题。
- 优先做纯线矢量 SVG（透明背景），对比有色透明 PNG 原生插图；决策基于页面实际观感，不依据工具喜好。
- 重要微动效由真实的交互状态触发，避免开屏充满与用户动作无关的演出。

## 07 两个任务合并，不是互相覆盖

- **资产侧（前 Fork A）** 负责：参考研究、线描人物是否成立、瓶子自身怎样成为美学器物、透明导出格式。以 [Fork A 08](https://www.figma.com/design/pIL4mlWLHxph3pqXlIVq1s?node-id=188-2) 和 [09 桌面十五瓶结构](https://www.figma.com/design/pIL4mlWLHxph3pqXlIVq1s?node-id=196-2) 为可查证参考，而不是直接覆盖。
- **交互与编排侧（前 Fork B）** 负责：P1 多心声、页面张力、瓶子怎样被看懂、P1 到 P2 的视觉连续性。以 [B 版多声部](https://www.figma.com/design/pIL4mlWLHxph3pqXlIVq1s?node-id=196-960) 和 [新三案](https://www.figma.com/design/pIL4mlWLHxph3pqXlIVq1s?node-id=205-2) 为废案/试案对照，保留已认可的骨架，不承诺它们已经达到视觉完成度。
- **合流交付** 是一张“视觉语法板＋资产试件＋P1/P2 组合示范”链，审核通过才批量生产，不需要重新开独立讨论分支。

## 08 下一步实际执行及验收

1. 从截图和原画核对 Alex Valcarcel 的**图解式人体外轮廓**、图形与文字叠加的核心特征，创作自己的原始线描，拒绝描摹对标。
2. 在 Figma 另做**视觉语法板 01**，隔离保存“人物姿态/瓶形/几何图解/批注/字形”各层，并展示两个尺度的组合，不覆盖 P1 母版。
3. 样件审查四个维度：轮廓识别、是否真正具备美学差异、与 G17 是否和谐、缩到手机上能否看清。
4. 用户只需判定方向及问题：保留、修改、放弃，**不迫使在不满意样稿中强选**。之后才进入 P1/P2 真正组装。
5. Figma 静态板的存在不等于 SVG/PNG 二进制已入 GitHub，不等于点击功能实现或已经部署。

最后一条防跑偏原则：**资产是为表达与交互服务的，不是先收集一堆装饰再强塞上页面。**
