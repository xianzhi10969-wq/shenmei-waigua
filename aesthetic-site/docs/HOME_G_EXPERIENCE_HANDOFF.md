## 本轮解决的问题
F 版的艺术表达已经具备感染力，但「打开后不知道做什么」；最早废弃 Demo 的搜索、感觉标签和 Three Ways In 的功能线索被视觉稿削弱。用户要求：
1. **首屏就能操作**，而不是立即面对作品图书馆；
2. **P3 的预览应承接搜索和感觉辨认**，而不是重新要求用户自己逛风格词；
3. **艺术资源先问“你现在想找怎样的网站/资源”**，按任务返回小组精选，而非一开始列十个网站；
4. **意象实验室必须适配无限文本命题**，不能为每一个意象专属插画；参考 Starbucks 星星/扭蛋启发的“随机抽取与揭晓”体验，但不假装复刻其准确 UI。

## 推荐体验与信息架构
**P1 / 搜索优先。** 沿用 D/E 已认可的像素字标、雕版风格与右侧功能试阅窗。主动作是搜索「感觉 / 风格 / 画面」，提供可直接尝试的样例。与之并列的两条不同路径是「帮我辨认感觉」和「随机发现」。

**P2 / 视觉发现。** 完整保留 D 版认可的图版风格索引。它负责视觉吸引和随意发现，而不是承担用户输入的工作。

**P3 / 承接结果。** 由 P1 搜索词或「分辨感觉」选择引出候选风格，借鉴 Cosmos 的悬停 / 点击换作品预览。桌面 hover 同时具备 click/focus；移动端以 tap 为主。Figma 示例使用「清冷」，不是所有自然语言都已有语义理解。

**P4 / 好奇心与意象实验。** 使用旧数据库的好奇心问题和 46 道意象命题，后者已有三类运算「相遇＋ / 抽离－ / 替换→」及 `imageA,imageB,prompt,operation,theme` 字段。新版扭蛋机只需要一次性可复用的 SVG 容器和动态文字，不为每道题生成插画。G Figma 中 `120:2` 有三个真实数据示例：「时钟＋发芽」、「时钟－刻度」、「秒针→藤蔓」；真实随机、摇动动效和自定义自由输入仍须前端实现，当前 Figma 用离散点击状态表示。

**P5 / 艺术资源按任务检索。** 首先问“你现在想找什么？”，展示 4 种目标：视觉灵感、真实艺术作品、互动网页、可用创作素材。分别给出 2～3 个精选真实网站及用途说明，所有网站仍保留独立可点击外链。完整分类图鉴可作为二级入口。对应 10 条策展资源站的数据还仅在 GitHub `aesthetic-site/data/staging/art_resources_v1.json`，**未写入飞书 Base**。

**P6 / 继续探索。** 不再在页面末尾增加第二套无关搜索；回到搜索、随机发现或风格索引即可。

## 搜索技术边界
旧版已部署代码 `dist/app.js` 有真实搜索逻辑，使用章节、词条、感觉标签的字符串包含匹配；不能声称它已经支持「像小时候做过的梦」这样的自然语言语义匹配。正式实现需要真实词条关键词、同义词、感觉—风格关联数据，制定匹配和空结果兜底，再完善模糊排序与用户选项；首版不必调用实时生成式 AI。
Figma 搜索框仅是**固定“清冷”示例的交互原型**，不能真键盘输入。正式移动端搜索须提供键盘焦点、联想词、搜索结果状态及可返回路径。

## 本次 Figma 原型已验收的交互范围
- 手机首屏搜索 → 固定样例「清冷」结果 → V3 清冷阅读预览。
