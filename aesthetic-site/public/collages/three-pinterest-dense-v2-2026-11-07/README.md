## 文件

`*-desktop.svg` / `*-mobile.svg` 为可编辑拼贴；相应 `*-structure.svg` 为结构图。`data/*-layout.json` 记录每个片段双端坐标、裁切、案例ID、原图和出处。`masks.json` 是手工轮廓。`assets/`保存采用的原图与字体，`licenses/`保存字体许可。

`build.py` 可从已打包的assets、audit和data重建页面；本机还保留完整65附件的 originals/，它不属于发布包。`render.cjs`、`check.cjs`用于浏览器验证，其本机浏览器/依赖路径需要在其他机器按环境修改。`checks.json`和`audit/source-integrity.json`记录结果。

已检查六张实图、五个宽度，90个双端原图入口与来源映射、Esc关闭及编号开关通过。浏览器响应式验证，不等同真实手机硬件测试。原始小图放大后可能呈现原有颗粒。
