# 手机首页接缝与下落星修复

2026-11-07。当前可审预览 http://127.0.0.1:8840/entrance/?repair=20261107 。

## 定位与实现

原手机P2的160px上缘，是嵌在SVG里的780px宽位图。弯曲边界、拖尾和红心星均被压平，手机脚本仅滚动整张图。新代码裁去这一带的旧像素，将同一边界转为独立矢量轮廓，并用已选v4 B星的原SVG接入滚动坠落、过水变色及P2→P3交接。手机P1同时恢复已确认的构图A标题源文件。

`public/entrance/mobile-home-star.mjs` 为本轮新增的手机轨迹实现。四个问题共用一列，星经过这一区域时缩至45px图框、沿左侧空白通过，读完后恢复90px水面尺寸。此手机避让与缩放属于本轮响应式接法，视觉待审。P1开场显影、原星明灭与独立飞行分工，倒滚返回时恢复原星。

`src/home-seam/geometry.json` 保存源像素测量及矢量路径。725个有效采样点拟合既有波形，排除旧星区域，中心边界均方误差0.264 CSS px，最大0.967 CSS px。上下轮廓按原图间距重建，水纹为人工贴合原轮廓的贝塞尔路径，线形细节有近似。

P2楼梯及水面沿用现有原图。现存同场景背景母源最高仅600×1297，编号仍在原位图里，因此它们在高DPR手机上仍会偏软。修复后的接缝和B星可独立缩放，不能将此视为整幅背景已恢复高清。

## 来源与规则核验

- 按项目Editorial规则E05核查原画几何。P1原图和受保护v4目录逐文件SHA256与本轮之前的完整清单一致。新资产另用`m_p2_layered_v20261107.svg`，原图留作源输入。
- 按E06检查跨屏节奏。开场显影约2.9秒，随后由用户滚动控制星星下落，水面停留后进入原P3转场，反向滚动复现同一状态。
- 按E07拆分工程层。星使用既有B墨色/米色SVG，波形坐标为独立JSON，手机运动为独立模块。运行层为HTML/SVG，本轮无Figma节点交付。
- 依据已读取的上游`page-composition.md`与`editorial-layout.md`检查艺术留白和跨屏连续性。来源为 https://github.com/medoismail/grid-systems-editorial-skill 。

## 检查与重建

运行 `python3 scripts/build_home_seam.py` 可从已附原SVG和坐标重建新版接缝资产，仅使用Python标准库。

`checks/home_seam.py` 在320/390/430宽、DPR2/3下逐一抽查101个滚动位置，核对文字避让、反向状态、星星交接与横向溢出。需Playwright、Chrome及Playwright ffmpeg。结果在`checks/home-seam/verification.json`，最大交接误差0.013 CSS px。另核查1440桌面及减少动态效果偏好，资源/脚本报错为0。整站24章/101词条/144案例及主要功能阅读回归通过；导航测试初次遇到章页滚动恢复时序失败，单独复测通过。

实际浏览器录屏和双端截图位于本地`output/home-seam-fix-2026-11-07/`。手机尺寸为浏览器仿真，真机视觉与触摸流畅度仍待用户审阅。
