## 源码结构

- `public/` 是可直接由静态服务器托管的完整网站。部署时以此为站点根目录。
- `public/entrance/` 为保留当前画面与动效的首页和星星目录。
- `public/app.js` / `style.css` 为专题与案例路由。
- `public/terms/` 为从真实快照生成的101个词条页面。
- `public/term-assets/term-page.js` 为共用的双向滚动、逐件显现、组图和返回逻辑，其余CSS保留当前已确认排版。
- `public/api/` 为静态导出的目录与详情，前端通过fetch读取。全部为本地文件，普通静态宿主即可运行。
- `public/media/` 是407份飞书原图，文件字节保留。
- `public/features/` 为已有功能页实现及当前只读数据。
- `public/resources/` 为P5独立组件及整站宿主。
- `src/catalog.json` / `features.json` 为本次展示的规范化数据，`source-status.json` 记录核验版本和内容缺口。
- `src/term/` 保留已确认词条源模板，`scripts/build.py` 重建全量词条，`scripts/build_features.py` 重建功能数据。
- `scripts/build_fonts.py` 通过原朱雀仿宋字体补齐动态中文字符。重建字体需要 `fonttools` 和 `brotli`，网站运行只需Python标准库。
